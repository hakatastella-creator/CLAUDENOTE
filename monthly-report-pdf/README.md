# 月次レポート（PDF版）

HTML版「月次レポート作成」と同じレイアウト（KPIカード＋表＋横棒グラフ）をゴールド基調で出力します。

## 毎月の作り方
1. `data/2026-10.json` をコピーして `data/2026-11.json` を作り、数字を書き換える
2. 実行: `python monthly-report-pdf/build_report.py monthly-report-pdf/data/2026-11.json`
3. `月次レポート_2026-11.pdf` ができる

## 計算
- 月売上 ＝ 合計点数×10 ＋ 自費請求額（個人別） ＋ 販売品目（未収金は含めない）
- 達成率 ＝ 月売上 ÷ 10,000,000
- キャンセル率 ＝ キャンセル数 ÷（来院件数＋キャンセル数）、来院件数 ＝ 総予約件数 − キャンセル数
- エアフロー：件数・売上・単価（売上÷件数）・物販に占める割合（売上÷販売品目）
- 金額は「¥11,053,540（約1,105万4千円）」形式で併記（千円単位で四捨五入）
