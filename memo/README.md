# 受付メモ

受付で「いま思いついたこと」をスマホからその場で入れて、リストで管理するためのメモアプリです。
パソコンを開く必要はありません。

**公開URL**: https://claude.ai/code/artifact/d1988dc7-262c-4e13-8760-3b1363e1b44a

## 使いかた

1. スマホのブラウザで上のURLを開く
2. 「共有」→「ホーム画面に追加」でアイコンを置く（次からは1タップで起動）
3. 下の入力欄に打って ↑ ボタン。分類チップ（やること／院長から／申し送り／買うもの）は
   最後に選んだものが次回も選ばれたままになります
4. 終わったメモはタップで完了。もう一度タップで戻せます
5. 完了したものは一番下の「完了 n件」にたたまれ、「完了を消す」でまとめて片付きます

上部のタブで分類ごとの絞り込みと残件数の確認ができます。

## 保存のしくみ

- メモは Artifact の保存領域（`data/state.json`）に書き込まれ、同じURLを開いた
  どの端末からでも同じリストが見えます
- 端末側にも控えを持つので、電波が悪いときも入力は消えません。つながったときに保存されます
- 2人が同時に書いても、メモ単位で突き合わせて統合するので取りこぼしません
- ヘッダー右の表示が保存状態です（保存済み／保存中…／保存できません／この端末のみ／閲覧のみ）

## スタッフへの共有

Artifact のページ右上の共有メニューから共有します。**編集権限**を渡した人だけが
メモを追加・完了できます。閲覧のみの人には入力欄が出ず、「閲覧のみ」と表示されます。

## 開発メモ

`index.html` が本体です（1ファイル完結、外部依存は Google Fonts のみ）。
更新するときは同じファイルを再公開すればURLは変わりません。ただし再公開の前に
公開中の内容を読み込んで、その時点のメモを引き継いでください。
