# 受付メモ

受付で「いま思いついたこと」をスマホからその場で入れて、リストで管理するためのメモアプリです。
パソコンを開く必要はありません。

**公開URL**: https://claude.ai/code/artifact/d1988dc7-262c-4e13-8760-3b1363e1b44a

## 使いかた

1. スマホのブラウザで上のURLを開く
2. 「共有」→「ホーム画面に追加」でアイコンを置く（次からは1タップで起動）
3. 下の入力欄に打って ↑ ボタン。フォルダのチップは最後に選んだものが次回も選ばれたままです
4. 終わったメモはタップで完了。もう一度タップで戻せます
5. 完了したものは一番下の「完了 n件」にたたまれ、「完了を消す」でまとめて片付きます

上部のタブでフォルダごとの絞り込みと残件数を確認できます。

## フォルダ

初期フォルダは **やること / 院長から / 毎月やること / 買うもの** の4つです。
入力欄の右にある歯車ボタンから、フォルダの追加・名前変更・色の変更・削除ができます。

- フォルダを削除すると、中のメモは残った先頭のフォルダへ移ります（メモは消えません）
- 削除ボタンは、移動先とメモの件数を表示してから2度目のタップで実行されます

### 毎月リセット

フォルダに「毎月リセット」を付けると、**月が変わったときにそのフォルダのチェックが自動で外れます**。
毎月やること（勤怠締め切り、シフト送付、キャンペーン決めなど）の置き場に使います。

- 判定は「そのメモをチェックした月が今月かどうか」で決まります。定期実行の仕組みは不要で、
  どの端末で開いても同じ結果になります
- 毎月リセットのフォルダのメモは「完了を消す」の対象外です（翌月また使うため）
- 一覧では、毎月リセットのフォルダ名の前に `↻` が付きます

## 保存のしくみ

- メモはこのページ自身の新しいバージョンとして保存され、同じURLを開いた
  どの端末からでも同じリストが見えます
- 端末側にも控えを持つので、電波が悪いときも入力は消えません。つながったときに保存されます
- 2人が同時に書いても、メモ単位・フォルダ単位で突き合わせて統合するので取りこぼしません
  （削除は21日間の墓標を持たせ、消したものが復活しないようにしています）
- ヘッダー右の表示が保存状態です（保存済み／保存中…／保存できません／この端末のみ／閲覧のみ）

## スタッフへの共有

Artifact のページ右上の共有メニューから共有します。**編集権限**を渡した人だけが
メモを追加・完了できます。閲覧のみの人には入力欄が出ず、「閲覧のみ」と表示されます。
共有された側も自分の Claude アカウントでのサインインが必要です。

## 開発メモ

`index.html` が本体です（1ファイル完結、外部依存は Google Fonts のみ）。
状態はページ内の `<script id="app-state">` に JSON で埋め込まれ、保存時はページ自身の
公開ソースを取得してこのブロックだけを差し替えて再公開します。

更新するときは同じファイルを再公開すればURLは変わりません。**再公開の前に必ず
公開中の版を読み、その時点の `app-state` を新しいファイルに引き継いでください。**
引き継がずに公開すると、スタッフが入れたメモが消えます。
