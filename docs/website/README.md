## 医院でご記入が必要な箇所

原稿内の【　】は未確定項目です。制作会社へ渡す前に埋めてください。

- ガミースマイル治療の費用（1歯あたり・税込）
- 治療期間・来院回数の目安
- 症例ごとの通院期間・来院回数・治療費の総額・使用材料名
- 症例写真のファイル名と掲載順
- 希望納期、制作会社の担当者名

## 掲載時の必須要件

自由診療の内容・症例写真を掲載するため、1メニュー・1症例ごとに
「治療内容／標準的な費用／治療期間および回数／主なリスク・副作用」の4項目を必ず併記します。
詳細は `02-case-gallery-ceramic-veneer.md` の「掲載前チェックリスト」を参照してください。
