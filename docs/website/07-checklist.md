## 進め方の目安

1. **A-1 の期間を確認**（1〜3ヶ月で問題なければ、この項目は完了）
2. **A-2 の症例情報をカルテから拾う**（ガミースマイル1件だけでも先に進められます）
3. **A-3 の写真を準備**
4. **B を制作会社に問い合わせ**（見積りと納期、症例集のURL）
5. **D を埋めてメール送信**

症例2〜4がすぐに揃わない場合は、**ガミースマイル1件だけで先に公開し、
セラミック・ラミネートベニアは後から追加**する形でも問題ありません。
その場合、制作会社への依頼は1回で済ませたいので、
「後日追加する前提でフォーマットだけ作っておいてください」と伝えておくと二度手間になりません。
