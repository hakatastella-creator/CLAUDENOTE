# SEO・MEO 設定書（歯冠長延長術／ガミースマイル）

制作会社への指示と、医院で行うGoogleビジネスプロフィールの設定をまとめています。

---

## 0. 最も効果が大きい判断：独立ページにするかどうか

現状の予定は `/whitening/#a○○` の**ページ内アンカー**です。この形だと、
検索結果に出るのはホワイトニングページであり、「ガミースマイル 福岡」で上位を狙うのは不利です。

| | ページ内アンカー | 独立ページ（推奨） |
| --- | --- | --- |
| URL | /whitening/#a○○ | /gummy-smile/ |
| タイトルタグ | ホワイトニングページのもの | ガミースマイル専用にできる |
| 検索での立ち位置 | ホワイトニングの一部 | 「ガミースマイル 福岡」の受け皿になる |
| 制作費 | 安い | 1ページ分かかる |

**推奨**：独立ページ `/gummy-smile/` を作り、`/whitening/` の診療メニュー一覧からは
そこへリンクする形（一覧には名称＋リード文だけ置く）。
予算やスケジュールの都合でアンカーのままにする場合も、以下の設定はすべて有効です。

**推奨URL**：`https://www.stella-dc.net/gummy-smile/`
（`/crown-lengthening/` より、検索されている語である `gummy-smile` を優先）

## 1. キーワード設計

検索されている語は「歯冠長延長術」より「ガミースマイル」が圧倒的に多いため、
**表に出す言葉はガミースマイル、専門用語は併記**という順序にします。

| 区分 | キーワード | 使う場所 |
| --- | --- | --- |
| 主軸 | ガミースマイル 福岡／ガミースマイル 博多 | タイトルタグ、H1、リード文 |
| 主軸 | 歯冠長延長術 福岡／クラウンレングスニング 福岡 | H1の括弧内、本文、alt |
| 準主軸 | 笑うと歯茎が見える 治療／歯ぐき 整形 福岡／歯が短い 治療 | 本文中の見出しと導入文 |
| ロングテール | ガミースマイル 費用／ガミースマイル 保険／ガミースマイル 治療 期間／ガミースマイル 手術 痛み | Q&A、費用表の見出し |
| ロングテール | 抜歯と言われた 歯 残したい 福岡／歯茎のライン 左右差 | 本文中の該当段落 |
| 指名・地域 | 博多ステラ歯科／博多駅 歯科 審美 | フッター、医院情報欄 |

**やらないこと**：同じ語を不自然に繰り返す、地域名を羅列する（福岡市博多区・中央区・早良区…）。
医療系は特に品質評価が厳しく、逆効果になります。地域名は自然に2〜3回で十分です。

## 2. 制作会社に指定するタグ類

**タイトルタグ（32文字前後）**
```
ガミースマイル治療（歯冠長延長術）｜福岡・博多の博多ステラ歯科・矯正歯科
```

**メタディスクリプション（120字前後）**
```
福岡市博多区の博多ステラ歯科・矯正歯科では、笑うと歯ぐきが目立つガミースマイルを歯冠長延長術で改善します。歯ぐきと骨のラインを整え、歯の見えている部分の長さを回復。費用・治療期間・症例写真を掲載しています。
```

**見出し構成（この階層で組んでください）**

| レベル | 内容 |
| --- | --- |
| H1 | ガミースマイル治療（歯冠長延長術） |
| H2 | ガミースマイルとは |
| H2 | こんな方に |
| H2 | 治療の内容 |
| H2 | 費用（自由診療・税込） |
| H2 | 治療期間・回数 |
| H2 | リスク・副作用 |
| H2 | 症例 |
| H2 | よくあるご質問 |

**画像ファイル名とalt**

| ファイル名 | alt属性 |
| --- | --- |
| gummy-smile-before.jpg | ガミースマイル治療前の口元（福岡市博多区 博多ステラ歯科） |
| gummy-smile-after.jpg | 歯冠長延長術により歯ぐきのラインを整えた治療後の口元 |

**内部リンク（制作会社へ）**
- ホワイトニングページの診療メニュー一覧 → 本ページ
- セラミック治療ページ →「歯ぐきのラインが気になる方は歯冠長延長術も併用します」の一文でリンク
- 本ページ → セラミック治療ページ、症例集ページ、治療費ページ、WEB予約
- パンくずリスト（トップ ＞ 診療メニュー ＞ ガミースマイル治療）を設置し、構造化データも出力

## 3. 構造化データ（制作会社へ）

`<head>` または本文末尾に JSON-LD で出力してください。**NAPは Googleビジネスプロフィールと1文字単位で一致**させること（表記ゆれがMEOで最も効きます）。

```json
{
  "@context": "https://schema.org",
  "@type": "MedicalWebPage",
  "name": "ガミースマイル治療（歯冠長延長術）",
  "url": "https://www.stella-dc.net/gummy-smile/",
  "about": {
    "@type": "MedicalProcedure",
    "name": "歯冠長延長術（クラウンレングスニング）",
    "procedureType": "https://schema.org/SurgicalProcedure",
    "howPerformed": "局所麻酔下で歯ぐきと歯槽骨のラインを整え、歯冠の長さを回復させます。"
  },
  "provider": {
    "@type": "Dentist",
    "name": "博多ステラ歯科・矯正歯科",
    "telephone": "092-409-8241",
    "url": "https://www.stella-dc.net/",
    "address": {
      "@type": "PostalAddress",
      "addressCountry": "JP",
      "addressRegion": "福岡県",
      "addressLocality": "福岡市博多区",
      "streetAddress": "【住所】",
      "postalCode": "【〒】"
    }
  }
}
```

**FAQ構造化データについて**：Googleは2023年以降、FAQリッチリザルトの表示を
公的機関・医療系の一部サイトに限定しています。**検索結果での見た目の効果は期待しない**前提で、
内容整理のために出力する分には問題ありません。過度な期待はしないでください。

## 4. 本文に追加するQ&A（ロングテール対策）

検索窓に打たれている言葉をそのまま見出しにします。3問だけ追加してください。

**Q. ガミースマイルの治療費はいくらですか？**
A. 当院の歯冠長延長術は1歯あたり【　　】円（税込・自由診療）です。範囲や本数により変わりますので、診査のうえお見積りをお出しします。

**Q. ガミースマイルの治療に保険は使えますか？**
A. 審美目的の場合は自由診療となります。歯周治療の一環として保険が適用できる場合もありますので、診査のうえご説明します。

**Q. 治療にどのくらいの期間がかかりますか？**
A. 手術は1回、約30〜60分です。歯ぐきが安定するまで【1〜3】ヶ月ほどおき、必要な方はその後セラミックなどの被せ物に進みます。

## 5. MEO：Googleビジネスプロフィールの設定（医院で実施）

検索結果の地図枠は、ホームページの内容ではなく**プロフィールの充実度・口コミ・写真・投稿頻度**で決まります。ページを作るだけでは地図枠は動きません。

### 5-1. 一度だけ設定するもの

- [ ] **カテゴリ**：メインは「歯科医院」。追加カテゴリに「審美歯科」「矯正歯科」を設定
- [ ] **サービス**に項目を追加
      - 名称：ガミースマイル治療（歯冠長延長術）
      - 説明：歯ぐきと骨のラインを整え、歯の見えている部分の長さを回復させる処置です。笑ったときに歯ぐきが目立つ方に行います。（自由診療）
      - 価格：【　　】円
      - ※「セラミック治療」「ラミネートベニア」「ホワイトニング」も同様に登録
- [ ] **サービスの説明文から該当ページへリンク**（サービス単位でURLが設定できる場合）
- [ ] **NAP（医院名・住所・電話）をホームページ・各種ポータルと完全一致**させる
      「博多ステラ歯科・矯正歯科」の表記、番地の「-」と「丁目」の書き方まで統一
- [ ] **予約リンク**にWEB予約URLを設定
- [ ] **属性**（バリアフリー、駐車場、キャッシュレス決済など）を埋められるだけ埋める
- [ ] **営業時間・臨時休診**を最新に

### 5-2. 継続して行うもの

- [ ] **投稿**を月2〜4回。新メニュー告知は公開直後に1本
- [ ] **写真**を月に数枚。院内・スタッフ・設備。症例写真を投稿する場合は後述の注意あり
- [ ] **口コミへの返信**を全件。返信率と速度は評価に効きます
- [ ] **Q&A機能**に、よくある質問を医院側から投稿しておく（「ガミースマイルの治療はできますか？」など）

### 5-3. 公開時の投稿文案（そのまま使えます）

```
【新メニュー】ガミースマイル治療（歯冠長延長術）を始めました

「笑うと歯ぐきが目立つ」「歯が短く見える」——
その原因は歯の大きさではなく、歯ぐきと骨の位置にあることがあります。

歯冠長延長術は、歯ぐきと骨のラインを整えて歯の見えている部分の長さを
回復させる処置です。むし歯が深く「被せ物ができない」と言われた歯を
残す目的でも行っています。

局所麻酔下で行い、1歯あたり約30〜60分。
費用は【　　】円（税込・自由診療）です。
主なリスク・副作用：痛み・腫れ・歯ぐきが下がることで歯が長く見える場合あり・
まれに感染や歯ぐきが元の位置に戻ることがあります。

詳しくはホームページをご覧ください。
福岡市博多区・博多ステラ歯科・矯正歯科
```

### 5-4. MEOでやってはいけないこと

- 医院名に「博多ステラ歯科・矯正歯科【博多駅・ガミースマイル】」のようにキーワードを足す
  → **ガイドライン違反で表示停止のリスク**。実際の看板の名称と一致させること
- 口コミの依頼に謝礼・割引を付ける（医療広告ガイドラインでも景品表示法でもNG）
- 投稿に症例写真を載せる際、治療内容・費用・期間回数・リスク副作用の記載を省く
  → **Googleの投稿も「広告」に該当**します。文字数制限があるため、症例写真の投稿は
    ホームページの症例ページへ誘導する形が安全です

## 6. 公開後の確認（医院で実施）

- [ ] Google Search Console で新URLをインデックス登録リクエスト
- [ ] サイトマップXMLに新URLが含まれているか制作会社に確認
- [ ] 2〜4週間後、Search Console の検索パフォーマンスで
      「ガミースマイル」関連の表示回数が付き始めているか確認
- [ ] Googleビジネスプロフィールのインサイトで、検索クエリと電話・経路のアクションを確認

**期間の目安**：新規ページが検索結果で安定するまで通常3〜6ヶ月かかります。
公開後1ヶ月で順位が付かなくても異常ではありません。
逆に「1ヶ月で1位」を保証する業者の提案は避けてください。
