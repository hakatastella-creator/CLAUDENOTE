## 掲載の必須要件

自由診療の内容と症例写真を掲載するため、**1メニュー・1症例ごとに**「治療内容／標準的な費用／治療期間および回数／主なリスク・副作用」の記載が必要です。原稿に含めていますので、**削除・要約せずそのまま掲載**してください。

断定表現（必ず治る等）、最上級表現（日本一等）、他院との比較、患者さまの体験談、加工した術前術後写真は使用しないでください。
