## 3. 掲載にあたっての必須要件（医療広告ガイドライン対応）

自由診療の内容および症例写真を掲載するため、次の記載が**1メニュー・1症例ごとに必ず**必要です。原稿にはすでに含めていますので、**削除・要約せずにそのまま掲載**してください。

1. 治療内容の説明
2. 標準的な費用（税込・自由診療である旨）
3. 治療期間および回数
4. 主なリスク・副作用

あわせて、以下は使用しないでください。

- 「必ず治る」「絶対に安全」「痛くない」等の断定表現
- 「日本一」「最高」等の最上級表現
- 他院との比較表現
- 患者さまの体験談
- 加工・修整した術前術後写真
