## 症例1：ラミネートベニア

- **タイトル**：ラミネートベニアで前歯の形と色を整えた症例
- **年代・性別**：【30代・女性】
- **主訴**：前歯の色と形が気になるとのことでご来院されました。
- **治療内容・使用材料**：歯の変色と形態不良と診断。歯を大きく削らずに改善できるラミネートベニアをご提案し、上顎前歯【　】本に薄いセラミックを接着しました。使用材料：【製品名】
- **治療期間／回数**：約【　】ヶ月／【　】回
- **費用**：【　　円】×【　】本＝【　　円（税込）】（自由診療）
- **主なリスク・副作用**：装着のため歯の表面をわずかに削る必要があり元には戻せません。治療後にしみることがあります。強い力で割れる・欠ける・外れることがあります。歯ぎしりのある方はナイトガードの併用をおすすめする場合があります。

## 症例2：セラミッククラウン

- **タイトル**：金属の被せ物をセラミックに変えて自然な見た目を回復した症例
- **年代・性別**：【40代・男性】
- **主訴**：前歯の被せ物の色と、歯ぐきの境目の黒ずみが気になるとのことでご来院されました。
- **治療内容・使用材料**：既存補綴物の適合不良と審美不良と診断。被せ物を除去し土台からやり直したうえで、オールセラミッククラウン【　】本を装着しました。使用材料：【製品名】
- **治療期間／回数**：約【　】ヶ月／【　】回
- **費用**：【　　円】×【　】本＝【　　円（税込）】（自由診療）
- **主なリスク・副作用**：製作にあたり歯を削る必要があります。強い衝撃で割れる・欠けることがあります。歯ぐきが下がると境目が見えてくることがあります。装着後もむし歯・歯周病になる可能性があり、定期的なメインテナンスが必要です。

## 症例3：歯冠長延長術＋セラミック

- **タイトル**：歯ぐきのラインを整えてからセラミックを装着した症例
- **年代・性別**：【20代・女性】
- **主訴**：笑うと歯ぐきが目立ち、左右の高さも揃っていないとのことでご来院されました。
- **治療内容・使用材料**：歯冠長延長術で歯ぐきと骨のラインを整え、治癒を待って上顎前歯【　】本にセラミッククラウンを装着しました。使用材料：【製品名】
- **治療期間／回数**：約【　】ヶ月／【　】回
- **費用**：合計【　　円（税込）】（自由診療）
- **主なリスク・副作用**：術後の腫れ・痛み・出血、知覚過敏、歯ぐきが下がることによる歯の長さの変化、まれに感染。セラミックは強い力で割れる・欠けることがあります。

## 掲載前チェックリスト

- [ ] 術前・術後で撮影角度・明るさ・条件が揃っている／加工していない
- [ ] 「Before」「After」の表記がある
- [ ] 4項目（治療内容・費用・期間回数・リスク副作用）が症例ごとに記載されている
- [ ] 断定表現（必ず治る等）、最上級表現（日本一等）、他院比較、体験談を使っていない
- [ ] 個人が特定される情報を含まない／掲載同意を書面で取得済み
- [ ] 海外製の未承認材料を使った場合、①未承認である旨 ②入手経路 ③国内承認品の有無 ④諸外国での安全性情報 を明記
- [ ] 「自由診療」「結果には個人差がある」旨の注意書きがある

## 写真を選ぶときの基準

院内の症例管理システムから選ぶ場合、次を満たすものを優先してください。

- 術前・術後で角度・距離・明るさ・背景が揃っている
- ピントが合っており、唾液の反射や血液が写っていない
- 顔全体が写っておらず個人が特定されない（口元のみのトリミングは可／変形加工は不可）
- 掲載同意を書面で取得済み、または改めて取得できる
- カルテから治療内容・費用・期間・回数・リスクを正確に書き起こせる
- 説明を読まなくても変化が写真で伝わる
