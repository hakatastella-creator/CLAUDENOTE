## A. 症例カードの共通フォーマット（制作会社への仕様）

各症例は、次の並び順で1カードにまとめてください。

1. 症例タイトル（例：ラミネートベニアで前歯の形と色を整えた症例）

8. 費用（税込・自由診療である旨）

## B. 症例原稿（雛形＋記入例）

### 症例1：ラミネートベニア（前歯の形・色）

- **タイトル**：ラミネートベニアで前歯の形と色を整えた症例
- **年代・性別**：【30代・女性】
- **主訴**：「前歯の色が黄ばんで見える」「歯の形が不揃いで、笑ったときに気になる」とのことでご来院されました。
- **診断・治療内容**：歯の変色と形態不良と診断。歯を大きく削らずに改善できるラミネートベニアをご提案し、上顎前歯【　】本にセラミック製の薄いシェルを接着しました。事前に仮歯で形と色をご確認いただいたうえで、最終的な形態を決定しています。
- **使用した材料・装置**：セラミック（ラミネートベニア）／【e.max 等の製品名】
- **治療期間／通院回数**：約【　】ヶ月／【　】回
- **費用**：【　　　　円（税込）】×【　】本＝【　　　　円（税込）】（自由診療）
- **主なリスク・副作用**：
  - 装着のために歯の表面をわずかに削る必要があり、元の状態には戻せません。
  - 治療後に歯がしみる（知覚過敏）ことがあります。
  - 強い力や噛み合わせによって、割れる・欠ける・外れることがあります。
  - 天然歯とセラミックでは、経年的な色調の変化の仕方が異なります。
  - 歯ぎしり・食いしばりのある方は、ナイトガードの併用をおすすめする場合があります。
  - 適切なメインテナンスを行わないと、周囲の歯ぐきの炎症やむし歯の原因になることがあります。

### 症例2：セラミッククラウン（オールセラミック／ジルコニア）

- **タイトル**：金属の被せ物をセラミックに変えて、自然な見た目を回復した症例
- **年代・性別**：【40代・男性】
- **主訴**：「前歯の被せ物の色が周りと合っていない」「歯ぐきの境目が黒く見える」とのことでご来院されました。
- **診断・治療内容**：既存補綴物の適合不良と審美不良、および歯ぐきの退縮による金属色の露出と診断。既存の被せ物を除去し、土台からやり直したうえで、オールセラミッククラウン【　】本を製作・装着しました。
- **使用した材料・装置**：オールセラミッククラウン／ジルコニアセラミック（【製品名】）
- **治療期間／通院回数**：約【　】ヶ月／【　】回
- **費用**：【　　　　円（税込）】×【　】本＝【　　　　円（税込）】（自由診療）
- **主なリスク・副作用**：
  - 被せ物の製作にあたり、歯を削る必要があります。
  - 神経のない歯では、歯の根の状態によって再治療や抜歯が必要になることがあります。
  - 強い衝撃や噛み合わせによって、割れる・欠けることがあります。
  - 歯ぐきが下がると、境目が見えてくることがあります。
  - 装着後もむし歯・歯周病になる可能性があり、定期的なメインテナンスが必要です。

### 症例3：歯冠長延長術＋セラミック（複合症例）

- **タイトル**：歯ぐきのラインを整えてからセラミックを装着した症例
- **年代・性別**：【20代・女性】
- **主訴**：「笑うと歯ぐきが目立つ」「左右で歯ぐきの高さが違う」とのことでご来院されました。
- **診断・治療内容**：歯ぐきの位置による審美不良と診断。歯冠長延長術で歯ぐきと骨のラインを整え、治癒を待ってから上顎前歯【　】本にセラミッククラウンを装着しました。
- **使用した材料・装置**：オールセラミッククラウン（【製品名】）
- **治療期間／通院回数**：約【　】ヶ月／【　】回
- **費用**：歯冠長延長術【　　　円（税込）】＋セラミック【　　　円（税込）】×【　】本＝合計【　　　　円（税込）】（自由診療）
- **主なリスク・副作用**：術後の腫れ・痛み・出血、知覚過敏、歯ぐきが下がることによる歯の長さの変化、まれに感染。セラミックは強い力で割れる・欠けることがあります。詳細は各治療ページをご覧ください。
