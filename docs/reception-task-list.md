# 受付 手が空いたときのやることリスト

診療の合間や患者さまの流れが途切れたときに、上から順に確認していくためのリストです。
**所要時間の目安ごと**に分けてあるので、「あと5分空いた」「30分まとまって取れそう」に合わせて選んでください。

> 迷ったら **① 患者さま対応に直結すること → ② 院内の環境 → ③ 先の仕込み** の順で。

---

## 5分でできること（すきま時間）

- [ ] 受付カウンターの上を片づける（書類・私物・ペンを定位置に戻す）
- [ ] 待合室の見回り（雑誌・スリッパの整列、ゴミ、椅子の位置）
- [ ] 消毒拭き（カウンター、ドアノブ、タッチパネル、キッズスペース、ペン、クリップボード）
- [ ] 本日の残り予約の再確認（次に来る患者さま、担当、処置内容）
- [ ] 電話メモ・伝言の処理漏れチェック（折り返し待ちが残っていないか）
- [ ] 会計待ち・処置待ちの患者さまの状況確認（お待たせしていないか声かけ）
- [ ] 診察券・問診票・アポイントカード・封筒・釣銭の残数確認
- [ ] プリンター用紙・レシートロール・インクの残量確認

## 10〜15分でできること

- [ ] **翌日・翌々日の予約確認連絡**（電話 / SMS / LINE）
- [ ] キャンセル・変更で空いた枠の埋め込み（キャンセル待ちリストへ案内）
- [ ] 保険証の確認漏れチェック（特に月初、期限切れ・変更の有無）
- [ ] 未収金・立替分のリスト確認と、次回来院時の声かけメモ入れ
- [ ] 自費の見積書・同意書の準備（明日以降の予定患者さま分）
- [ ] カルテ・書類のファイリング、スキャン取り込み
- [ ] 紹介状・診療情報提供書・領収書の再発行依頼への対応
- [ ] リコールハガキ / メールの宛名準備・発送
- [ ] 物販（歯ブラシ・フロス・洗口液など）の陳列と在庫チェック

## 30分以上まとまって取れるとき

- [ ] **中断患者さま（未来院）へのリコール連絡**（最終来院から◯ヶ月リストを作成 → 連絡）
- [ ] 定期健診リコール名簿の作成・更新
- [ ] レセプト点検（月初は最優先）
- [ ] 受付・事務備品の在庫確認と発注
- [ ] 院内掲示物・POP・料金表の更新（古い情報が貼りっぱなしになっていないか）
- [ ] LINE公式 / Instagram / ホームページの更新、口コミへの返信
- [ ] 申し送りノート・受付マニュアルの整備（新しく決まったルールの反映）
- [ ] ロールプレイ練習（電話応対、自費説明、初診カウンセリング）
- [ ] 予約状況の振り返り（キャンセル率、空き枠の傾向、混雑時間帯）

---

## 定期でやること

### 毎日
- 朝：本日の予約表の確認、釣銭準備、待合・受付の清掃、前日の申し送り確認
- 昼：午後の予約確認、電話対応の残タスク処理
- 夕：翌日の準備（カルテ・書類）、レジ締め、戸締まり前の見回り

### 毎週
- 予約表の1週間先まで確認（空き枠・ダブルブッキング）
- 備品の棚卸しと発注
- 掲示物・物販まわりの入れ替え

### 毎月
- 月初：保険証の一斉確認
- 月初〜10日：レセプト提出
- 月末：未収金の整理、リコール対象者の抽出

---

## 気をつけたいこと

- 患者さまから見える場所で、私語・スマホ・作業に没頭しない（顔を上げて挨拶できる状態を保つ）
- 個人情報が写った書類・画面を、カウンターや待合から見える状態で放置しない
- 手が空いたら「何かやることありますか？」より先に、このリストを一巡する
- 途中まで進めた作業は、申し送りノートに残してから引き継ぐ
