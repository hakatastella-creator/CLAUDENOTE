# テレビCM 企画書

「はがきが七円だった頃。」

対象：株式会社FEA／NBC長崎 資産運用セミナー
本書は `senior-asset-seminar-plan.md` `referral-strategy.md` と一体で機能する。

---

## 0. 前提

**現行CMは未視聴。** 以下の診断は、地方の金融サービスCMに共通する失敗の型を挙げたもので、
現行CMを名指しで批評したものではない。実物を確認のうえ差し替える。

---

## 1. なぜ「何を伝えたいのかわからない」が起きるか

金融サービスのCMは、ほぼ例外なく次の5つで崩れる。

| # | 失敗の型 | 起きること |
|---|---|---|
| 1 | **詰め込みすぎ** ─ 資産運用・保険・相続・NISA・家計改善を全部言う | 1つも残らない |
| 2 | **会社が主語** ─「FEAは、お客様に寄り添い…」 | 視聴者は自分に関係ないと判断して見なくなる |
| 3 | **抽象語** ─「安心」「未来」「豊かな暮らし」 | 映像が頭に浮かばない＝記憶に残らない |
| 4 | **冒頭に営業担当の笑顔** | 「売り込みだ」と警戒スイッチが入り、以降届かない |
| 5 | **覚えられるフレーズがない** | 口コミで再現できない |

### 決定的なのは 5 番

**口コミで再現できないCMは、この層には無意味。**

- ✕「テレビでなんか、資産運用の会社がやってたよ」→ 何も伝わらない
- ○「はがきが七円だった頃の話、テレビでやってたよ」→ 会話が続き、セミナーに繋がる

CMの成否は「視聴者が友人に**言える一文**を持ち帰れるか」で決まる。

---

## 2. このCMの本当の仕事

**このCMで電話は鳴らない。鳴らそうとするから詰め込みすぎて、何も残らない。**

CMのKPIを、申込数から次の3つに置き換える。

| 役割 | 内容 |
|---|---|
| ① 想起の種 | 友人からセミナーの話を聞いたとき「テレビでやってたやつ？」と繋がる |
| ② 出前先での信頼 | 公民館・老人会に出向いたとき「あのCMの人だ」で警戒が解ける |
| ③ 子世代への刺激 | 帰省時に「親の通帳」を思い出させる |

いずれも `referral-strategy.md` の紹介・口コミ設計の**補強材**である。
CM単独で成果を測らない。

## 3. コンセプト

```
        はがきが、七円だった頃。
```

**この一本だけを言う。他は何も言わない。**

### なぜこれか

| 理由 | |
|---|---|
| **一つしか言っていない** | 「物価は上がる、預金は増えない」だけ。商品も制度も出さない |
| **自分で覚えている** | 70代は、はがき七円の時代を実際に生きている。データではなく記憶 |
| **人に話せる** | 「七円だったんだって」は会話になる。口コミの弾がCMそのもの |
| **映像が要らない** | 数字と静物だけで成立する。**制作費が極端に安い** |
| **シリーズ化できる** | 散髪代編、牛乳編…同型式で量産でき、反復で記憶に定着する |
| **セミナー本編と同じ** | 冒頭のクイズがそのままCM。CMと中身がズレない |

### 統一コピー（全素材で固定）

```
        増やす話の前に、減らさない話を。
```

## 4. 絵コンテ

### 15秒 ①「はがき」篇 ─ 想起専用

**15秒に告知を入れない。** 電話番号はテロップのみ、読み上げない。
15秒は記憶、30秒は告知、と役割を分ける。

| 秒 | 画 | ナレーション | テロップ |
|---|---|---|---|
| 0:00-0:04 | 白バック。古いはがきが一枚、静かに置かれる | はがきが、七円だった頃を／覚えていますか。 | **7円** |
| 0:04-0:07 | 同じ位置に、今のはがき | いまは、八十五円です。 | **85円** |
| 0:07-0:11 | 通帳のアップ。残高の数字。動かない | 預金の数字は、変わっていません。 | ─ |
| 0:11-0:15 | 通帳のまま、文字が乗る | 減っているのは、買えるものです。 | 増やす話の前に、減らさない話を。<br>お金の置き場所セミナー（小さく電話番号） |

ナレーション計62文字／15秒＝約4.1文字/秒。**この層向けにゆっくり読める速度。**

### 15秒 ②「散髪代」篇・③「牛乳」篇

## 5. 演出ルール

**このルールを守れば、誰が作っても崩れない。**

| 項目 | ルール | 理由 |
|---|---|---|
| **講師の顔** | **0:16まで出さない。**15秒版では出さない | 冒頭に営業担当が出ると警戒スイッチが入る |
| **ナレーション** | 低め、ゆっくり、4〜4.5文字/秒 | 高音と早口が聞き取りにくい |
| **テロップ** | 白地に黒。極太ゴシック。画面高の1/8以上 | 明朝・細字・薄いグレーは読めない |
| **色** | 白と黒が主。差し色は1色まで | 青と黒、黄と白の区別がつきにくい |
| **BGM** | 静かなピアノまたは無音。盛り上げない | 煽ると「怖がらせて売る」印象になる |
| **カット割** | 1カット3秒以上。速いカットは使わない | 追えない |
| **数字の見せ方** | 一画面に一つ。並べて比較しない | 比較は時間差でやる（7円 → 85円） |
| **感嘆符・効果音** | 使わない | 通販・詐欺の質感になる |

## 6. 出稿設計

### 枠

この層が見ている枠にだけ出す。プライム・深夜は捨てる。

1. **夕方のローカルニュース前後**（最優先）
2. 朝の情報番組
3. 大相撲・時代劇・健康番組
4. ラジオは平日午前〜昼の帯

### ローテーション

- 15秒3本（はがき／散髪代／牛乳）を**回して反復**させる
- 30秒はセミナー2週間前から集中投下
- 5秒IDで頻度を稼ぐ

**1本の凝ったCMより、同型式の15秒を3本回す方がこの層には効く。**
反復で「あのCM」として認識され、口コミの共通言語になる。

## 7. 制作費が安い理由

受注提案として、ここは明示する。

- ロケなし。**白ホリまたは卓上のみ**
- 出演者なし（30秒の講師カットのみ）
- 小道具は、はがき・通帳・散髪バサミ・牛乳瓶
- 15秒3本を**同日に一括撮影**できる
- 数字とテロップの差し替えだけで、翌年以降も使い回せる

**同じ予算で、露出量を数倍にできる。**

## 8. 考査・コンプライアンス

| 項目 | 対応 |
|---|---|
| 数字の根拠 | 総務省 小売物価統計調査・日本郵便の公表値。**出典を考査に添付** |
| 断定的表現 | 「必ず」「絶対」「確実に」は使わない |
| 商品名・利回り | **一切出さない。**本CMは商品広告ではない |
| 「何も売りません」 | **実際に売らないこと。**守れない約束は放送しない |
| 不安訴求 | 「減っている」で止めず、必ず「減らさない話を」で受ける |
| 最終確認 | 株式会社FEA のコンプライアンス確認、およびNBC考査を通す |

## 9. 効果測定

CMで電話は鳴らないので、**申込数でCMを評価しない。**

| 測る場所 | 方法 |
|---|---|
| 電話受付 | 「何でお知りになりましたか」の1問（テレビ／ラジオ／紹介／折込…） |
| アンケート | 同上の設問（既に Q5 として追加済み） |
| 出前先 | 「CMをご覧になった方は？」と挙手で聞く ← **ここが本命の指標** |
| 会話 | 「はがき七円」がセミナー会場で話題に出るか |

出前先での認知率が上がっていれば、CMは仕事をしている。
