# キャッチコピー集

`senior-asset-seminar-plan.md` 3章の展開版。
対象は63〜80歳、まとまった資金が普通預金にある層。

---

## 0. 前提 ― この世代のスイッチ

| 響く | 響かない（逆効果） |
|---|---|
| 損失の回避（もったいない） | 利益の獲得（増やしましょう） |
| 家族への責任 | 自分の楽しみ |
| 許可・労い（もう十分やった） | 啓蒙・命令（学びましょう） |
| 断り方を教えてくれる人 | 勧めてくる人 |
| 具体的な金額と年数 | 抽象的な「将来」「ゆとり」 |

**最重要：「シニア」「高齢者」「セカンドライフ」と呼ばれたくない世代。**
ターゲティングは媒体と内容で行い、紙面には一切書かない。
企画書側の「シニア向け」表記は社内用であり、対外物には出さない。

その他の原則

- 一息で読める長さ（主見出しは20字以内）
- ひらがな多め。カタカナは原則ゼロ
- 「あなた」ではなく「お手元の」「ご自身の」
- 感嘆符は使わない（通販・詐欺の紙面に見える）
- 疑問形は有効。ただし詰問調にしない

## 1. 推奨（主見出し）

```
    置いてあるだけで、減っています。

    増やす話の前に、減らさない話を。
```

**採用理由**

1. 「投資」「運用」を一言も使っていないので身構えられない
2. 矛盾で足が止まる。「置いてあるのに減る?」が、通帳の額面しか見ていない前提を1行で崩す
3. セミナーの中身とズレていない。実際に90分かけて話すのがこれなので、
   釣りコピーにならず「話が違う」が起きない

**注意：対句で必ずセット運用する。**
主見出し単独だと不安訴求だけが残る。サブの「減らさない話」が煽りを回収して安心に着地させている。

## 2. 軸別コピー集

### 軸① もったいない（目減り）

- 1,000万円が、1,000万円のままでいる怖さ。
- 金利ではなく、物価の話をします。
- 一番動かしていないお金が、一番目減りしています。
- 通帳の数字は減っていません。買えるものが減りました。

### 軸② 家族への責任 ― 集客力は最強

- **そのお金、ご家族はどこにあるかご存じですか。**
- 元気なうちにしか、できない手続きがあります。
- 遺すつもりのお金で、ご家族が困ることがあります。
- 通帳のありかを、一枚の紙に。

> ⚠ 「元気なうちにしか、できない手続きがあります。」は認知症パートの入口として
> 非常に強い一方、最も不安を煽る一文でもある。
> **必ず対処法とセットで使い、単独では出さない。**

### 軸③ 許可・労い ― 反発が最も少ない

- **貯めるのは、もう十分です。**
- いくらまで使っていいのか、決めていますか。
- 我慢して遺したお金より、喜ばれる渡し方を。

### 軸④ 断る力 ― 逆説的に信頼が一番上がる

- **勧誘はしません。断り方の話をします。**
- 銀行で勧められたあの商品、断れましたか。
- 決めるのは、お帰りになってからで結構です。

### 軸⑤ 罪悪感の解除

- 今さらではありません。今だからです。
- 知らなかったことを、責める会ではありません。

## 3. 使う場所別

### ラジオ 20秒（NBC自社枠）

```
通帳の数字は、減っていません。
でも、買えるものは減っています。
退職金や預金を、そのままにしていませんか。
増やす話の前に、減らさない話を。
お金の置き場所セミナー、参加無料。
お申し込みは、お電話で。
```

### 電話受付の第一声 ― 申込はここで落ちる

> 「お名前とお電話番号だけ伺えれば、**それで完了です**。
> 　難しいご記入は一切ございません。」

手続きの煩雑さへの警戒がこの層で最も強い。「それで完了です」を必ず言い切る。

### 会場入口のバナー

> 今日は、売りません。

### お礼はがきの一言（手書き）

> 通帳のありかだけでも、書いておかれてください。

## 4. 書いてはいけないコピー

| NG | 理由 |
|---|---|
| 今こそ資産運用を始めましょう! | 命令形＋カタカナ＋「今さら」を刺激する |
| 知らないと損をする! | 責める響き。「知らなかった」を恥と感じて来なくなる |
| あなたの資産、大丈夫ですか? | 詰問。「あなた」は距離が近すぎる（「お手元の」に） |
| 賢い人はもう始めています | 取り残され感で反発。比較は逆効果 |
| 無料セミナー開催!! | 何の会か不明。感嘆符の多用は通販・詐欺の紙面に見える |
| 老後2,000万円問題 | 使い古され、そもそも現役層向けの文脈 |
| アクティブシニアの皆様へ | 自分を高齢者と思っていない。この呼び方自体を嫌う |
| 元本保証／必ず／絶対に／確実に | 断定的判断の提供にあたる。コンプライアンス違反 |

## 5. 効き目の確かめ方

折込を2回に分けられる場合、次の2本を別日でテストする。

- **A：置いてあるだけで、減っています。** → 資金を持つ本人に効く
- **B：そのお金、ご家族はどこにあるかご存じですか。** → 子世代が親に勧める経路に効く

申込の電話で「**どちらのチラシをご覧になりましたか**」と1問聞くだけで判別できる。
受付表にA/B欄を1つ足しておく。
