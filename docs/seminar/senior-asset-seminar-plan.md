# シニア向け「資産運用セミナー」企画書

対象セミナー：NBC長崎「『このままで大丈夫?』を安心に変える 資産運用セミナー」
（長崎会場：中山 寛望さん／大村会場：舛田 莉子さん・株式会社FEA、MC 佐々木良子さん）

本書は、現行の**若年〜現役層向け（新NISA・つみたて訴求）**の内容を、
**「高齢・金融になじみが薄い・まとまった資金が預金に眠っている層」**へ振り直すための企画書です。

---

## 1. ターゲットの再定義

### 狙う人

| 項目 | 設定 |
|---|---|
| 年齢 | 63〜80歳（コアは68〜75歳） |
| 世帯 | 夫婦のみ、または配偶者と死別した単身。子は独立し県外にいることも多い |
| 資金 | 退職金・満期保険金・親からの相続金などで **500万〜3,000万円が普通預金に置きっぱなし** |
| 収入 | 公的年金が中心。毎月の生活はぎりぎり回っているが取り崩しが少しずつ進んでいる |
| 金融知識 | 定期預金と個人年金保険くらい。投資＝ギャンブル・損するもの、という認識 |
| 情報源 | 地元紙・折込チラシ・テレビ・ラジオ・近所の口コミ。ネット申込は苦手 |

### 「本当の関心事」は資産運用ではない

シニア層は「増やしたい」で動きません。実際に足を運ぶ動機は次の4つです。
ここを入口にしないと、そもそも席が埋まりません。

1. **お金が尽きないか**（何歳まで、いくら使っていいのか分からない）
2. **家族に迷惑をかけないか**（相続・葬式代・実家の片付け）
3. **物価が上がって預金が目減りしていないか**（実感として一番強い）
4. **騙されないか**（銀行・証券から勧誘された商品が良いのか判断できない）

> **企画の芯**：このセミナーは「運用商品を売る会」ではなく、
> **「まとまったお金の置き場所を整理し、家族に迷惑をかけない準備をする会」**として設計する。
> 結果として運用・保険の相談につながる、という順序を崩さない。

## 3. タイトル・キャッチコピー案

「資産運用セミナー」という言葉自体が、この層には**自分ごとになりません**（「運用するお金なんてない」と読まれる）。
タイトルで資金の存在を言い当てるのが最優先です。

**タイトル案（推奨順）**

1. **退職金・預金、そのままで大丈夫ですか？ ― 70代からのお金の置き場所**
2. **銀行に置いたままの1,000万円、10年後はいくらの価値？**
3. **使う・守る・遺す ― まとまったお金の分け方セミナー**
4. **家族に迷惑をかけないための、お金の整理術**

**サブコピー案**

- 「増やす話の前に、減らさない話をします。」
- 「投資の勧誘はいたしません。今あるお金の置き場所を一緒に整理します。」
- 「お一人でも、ご家族とご一緒でも。」

**チラシに必ず入れる一文**

> ご夫婦・親子でのご参加を歓迎します。お子さま世代の同席も大丈夫です。

家族同席の明示は、集客・信頼・後述のコンプライアンス対応の三つを同時に満たします。

## 5. 各パートの中身

### ① つかみ：30年前と今の値段（0-10分）

数字を並べるのではなく、**その場で当ててもらう**。会場が一気に温まります。

- はがき / 牛乳1本 / 散髪代 / 映画館 / 国立大の授業料 ―「昔いくらでしたか？」
- 「では、同じことが**これからの10年**にも起きるとしたら？」

> 目的は不安を煽ることではなく、**「預金の額面は減らないが、買えるものは減る」**という
> 一点を体感してもらうこと。ここが以降すべての土台になります。

### ② 預金だけに置くリスク（10-25分）

黒板的に、大きな数字ひとつで見せます。

- 物価が**年2%**上がる前提で、普通預金の1,000万円は
  - 10年後 … 買えるものは **約820万円分**
  - 20年後 … 買えるものは **約670万円分**
- 「額面は1,000万円のまま。減っていないのに、買えるものが減っている」

補足として、公的年金には物価に応じた調整の仕組みがある一方、
マクロ経済スライドにより**物価上昇ほどには増えない設計**であることに触れる。
（制度の細部には踏み込まず、「年金だけでは物価上昇を完全には吸収しない」に留める）

### ③ まとまったお金の三分法（30-50分）★本編

シニア向けの中核。**商品ではなく「順番」を教える**のがポイントです。

| 区分 | 中身 | 置き場所の考え方 |
|---|---|---|
| **① すぐ使うお金** | 生活費の3〜5年分、医療・介護の備え、葬儀費用 | 普通預金・定期預金。値動きするものに置かない |
| **② 10年くらい先に使うお金** | 家の修繕、車の買い替え、施設入居一時金 | 値動きの幅が小さいもの（個人向け国債・債券など） |
| **③ 当面使わない・遺すお金** | 子・孫に渡す予定のお金 | 期間が取れるので運用や保険の選択肢が出てくる |

**この場で書いてもらうワーク（5分）**
配布シートに「①いくら ②いくら ③いくら」を鉛筆で書いてもらう。
書けない人が大半です。**その「書けなさ」こそが個別相談の動機**になります。

> 講師の締め方：「金額が埋まらなかった方、それが普通です。
> ここを一緒に埋めるのが、私たちの仕事です。」

### ④ 認知症と口座凍結（50-65分）★最も刺さる

このパートを入れるかどうかで、シニア向けセミナーの成否が変わります。

- 判断能力が低下したと金融機関が確認した場合、**本人名義の口座からの引き出しや解約に制限がかかる**ことがある
- 家族であっても、代理での手続きは原則できない
- 結果として「お金はあるのに介護費用が払えない」状態が起こりうる

**元気なうちにできる備え（選択肢の紹介まで。個別の是非は相談で）**

- 金融機関の**代理人届出・代理人カード**の登録
- **任意後見契約**（元気なうちに、自分で後見人を決めておく）
- **家族信託**（財産の管理を家族に託す仕組み）
- 通帳・保険証券・不動産の**一覧化**（＝エンディングノート的な棚卸し）

> ここでの持ち帰り資料として **「わが家の資産一覧シート」** を配ると、
> アンケート回収率と個別相談申込率が明確に上がります。

### ⑤ 相続・贈与の基本（65-78分）

制度の詳細は税理士領域なので、**「知らないと損をする枠が2つある」**に絞ります。

- **相続税の基礎控除**：3,000万円 ＋ 600万円 × 法定相続人の数
  → 「まずご自身が対象になりうるかどうかを知る」
- **死亡保険金の非課税枠**：500万円 × 法定相続人の数
  → 「同じお金でも、預金のままか保険かで、遺る額が変わることがある」
- **暦年贈与**：年間110万円の基礎控除。ただし相続開始前の一定期間の贈与は
  相続財産に加算される取り扱いがある（近年の改正で加算期間が延長）
- **相続時精算課税**にも年110万円の基礎控除が設けられている

> 必ず添える一言：「税金の最終判断は税理士の領域です。
> ここでは『調べるべき論点』をお持ち帰りください。」
> 断定を避けることが、そのまま信頼と法令遵守の両方になります。

### ⑥ 怪しい話の見分け方（78-85分）

一見すると自社の不利になりますが、**この層に最も効く信頼構築**です。

- 「必ず儲かる」「元本保証で高利回り」→ その時点でおかしい
- **その場で契約を迫る**、家に上がり込んで長時間 → 断ってよい
- **家族に相談させない**、内緒にさせる → 危険信号
- 判断に迷ったら、**契約前に家族か第三者に話す**

> 「今日の私の話も、ご家族に話してから決めてください」で締めると、
> 押し売り感が消え、かえって個別相談の申込が増えます。

## 7. 資料・スライドの作り方

視力・聴力の変化を前提に設計します。若年層向けの資料をそのまま使うと読めません。

**文字**
- 本文 **24pt以上**、見出し32pt以上。配布資料は**14pt以上**
- 書体は**ゴシック体**（明朝は細くて読みにくい）
- 1スライド1メッセージ。箇条書きは**4行まで**

**色**
- 加齢により**青系と黒の区別、黄色と白の区別がつきにくくなる**
- 背景は白またはごく薄いクリーム、文字は濃い黒
- 強調は**赤よりも「太字＋下線」または濃いオレンジ**
- 薄いグレーの文字、色だけで意味を分ける表現は使わない

**中身**
- グラフは折れ線1本、棒グラフは3本まで
- 数字は**万円単位**に揃える（「1,000万円」であって「10百万円」ではない）
- 配布資料は**穴埋め式**にして、書き込みながら聞ける形にする

**配布物セット**
1. 講演資料（穴埋め式・14pt以上）
2. **わが家の資産一覧シート**（持ち帰りの主役）
3. 三分法の記入シート
4. アンケート（後述）
5. 個別相談の案内（電話番号を特大で）

## 9. 集客導線

Web中心の集客はこの層にはほぼ届きません。**申込のハードルを電話1本に下げる**のが最重要です。

**告知チャネル（優先順）**
1. **新聞折込チラシ**（土日朝刊）— この層への到達率が最も高い
2. **ラジオ**（NBCの自社媒体。平日午前〜昼の帯が親和性高い）
3. **テレビスポット**（夕方のニュース前後）
4. 公民館・地域包括支援センター・スーパー・調剤薬局・病院待合のポスター
5. **既存顧客からの紹介**（「ご友人とご一緒に」と明記した案内状）
6. Web（補助。子世代が親に勧める経路として機能する）

**申込動線**
- **電話番号を紙面で最大サイズ**に。受付時間を明記（平日9:00〜17:00 など）
- はがき・FAX申込も残す
- Webフォームは入力項目を**氏名・電話・参加希望回のみ**に絞る
- 申込者には**開催3日前に確認の電話**（当日欠席を大きく減らせる）

**チラシに書くべきこと / 書かないこと**

| 書く | 書かない |
|---|---|
| 参加無料・予約制・定員 | 具体的な商品名・利回り |
| 会場の1階／駐車場／所要時間 | 「必ず」「絶対」「確実に」 |
| 「勧誘はいたしません」 | 過度に不安を煽る表現 |
| ご家族同伴歓迎 | 難しいカタカナ語 |
| 手土産（ラ・メゾンのタルティ・メルティ等） | — |

## 10. アンケート設計

紙は**A4片面・1枚のみ**。字は大きく、記入欄も大きく。書く量が多いと回収率が落ちます。

**設問例**

1. 本日の内容はいかがでしたか（とても良かった／良かった／ふつう／わかりにくかった）
2. 今日、一番気になったのはどれですか（**複数選択可**）
   - 物価上昇でお金の値打ちが下がること
   - まとまったお金の分け方
   - 認知症になったときの口座のこと
   - 相続・贈与のこと
   - その他（　　　）
3. ご自宅で、通帳や保険証券の一覧を作っていますか（はい／いいえ／作りかけ）
4. 今後についてお伺いします（**1つだけ○**）
   - 一度、個別に話を聞いてみたい
   - 今日の資料をもう少し詳しくほしい
   - 今は必要ない
5. お名前・ご連絡先（任意）

> ポイント：設問4を「相談希望 はい／いいえ」にしない。
> **3択にすると中間層が「話を聞いてみたい」を選びやすくなります。**
> 設問3で「いいえ」と答えた人は、そのまま最有力の見込み客です。

**個人情報の取り扱い**
- 利用目的（個別相談のご案内に使う旨）をアンケート用紙に明記
- 「連絡不要」の意思表示欄を設ける

## 12. コンプライアンス上の注意（必読）

高齢者向けは、内容が良くても進め方を誤ると**後日の苦情・契約無効**に直結します。
以下は企画段階から織り込みます。**最終確認は必ず FEA 社および所属協会のルールに従ってください。**

**セミナーでの表現**
- **断定的判断の提供は禁止**（「必ず値上がりします」「絶対に損はしません」）
- 不確実な事柄について確実であると誤解させる表現をしない
- 特定商品を挙げる場合、リスク・手数料の説明が不可欠になる
  → **セミナーでは商品名を出さない設計**にしておくのが最も安全
- 過去の運用実績を将来の見込みとして示さない
- 税務・法務の断定を避け、**税理士・司法書士等の専門家へつなぐ**と明言する

**高齢のお客様への対応**
- 金融業界では、一定年齢以上のお客様について**役席者の事前承認、家族同席、複数回に分けた説明、即日受注の制限**などの社内ルールが定められているのが一般的
- 保険募集でも高齢者向けの募集ルール（家族同席・複数回の説明・記録の保存）がある
- **セミナー段階から「ご家族と一緒に」を打ち出す**ことで、後工程のルール順守が自然になる
- 当日、明らかに理解が難しそうな方には、その場で契約や申込に進ませない

**不安訴求の節度**
- 「目減り」「認知症」「相続」は、高齢者に対して**強く効きすぎる**テーマです
- 不安を提示したら、必ず**その場で対処法とセットで返す**
- 煽って終わる構成にしない（後日「怖がらせて売られた」という認識になりやすい）

**その他**
- アンケートの個人情報は利用目的を明示
- 会場での撮影・録音の可否を冒頭に案内
- 手土産の提供は景品表示法上の問題がない範囲か確認
