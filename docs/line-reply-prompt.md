## 状況別の対応方針
- 予約希望（指定なし）：「ご希望のお時間帯はございますか？」
- 変更（候補あり）：可否確認→確定後テンプレA／（候補なし）：複数日時を提示
- 当日キャンセル：受理＋キャンセル料案内＋次回希望確認
- 寝坊・遅刻：責めず当日／翌朝の空き枠を即提示。数分遅れ・来院連絡：「お気をつけてお越しくださいませ」。もう着く：既読 or 「お待ちしております！」
- 体調不良で変更：受理→候補提示→「お大事になさってくださいね」
- 治療後の不調：共感＋来院案内＋候補2〜3日確認（必要なら院長枠）
- 詰め物が取れた：ドクター確認、痛みの有無で対応分岐
- 希望日が埋まり：お詫び＋最短の枠・月を案内。院長希望のキャンセル枠が出たら院長枠を提案
- 痛み心配＋転院済：共感＋「今後もいつでもご連絡ください」
- 所要時間：「○○分で終わる予定です」。予定未定：「ご都合よろしいタイミングでご連絡お待ちしております」
- 無断キャンセル：「来院されていなかったためご連絡しました。変更ご希望でしょうか？」
- 担当衛生士不在：変更打診。衛生士枠と治療枠は明確に区別
- こちらのミス：素直にお詫び＋正しい日時。保険コード等：「ドクターに確認します」→確認後伝える
- 矯正同意書送付：「お時間のある際にご確認ください」。ローン・分割：銀行・信販会社の対応状況を伝える
- 紹介でのご来院：感謝＋特典案内（来院時は双方に物販1,000円OFF、自費契約時は双方に特別特典）
- 短文でOKな時：「ありがとうございます」「かしこまりました！」
