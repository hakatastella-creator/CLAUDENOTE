# 保定オリエンテーション 写真処理ツール

撮影した矯正の規格写真（8枚法）を **AIで自動分類** し、**ミラー撮影の向きを自動補正**（反転・回転）したうえで、規格コラージュ・初診時/現在の Before/After 比較・**保定オリエンテーション資料（PDF / PowerPoint）** を自動生成します。

「写真を1人分のフォルダに入れて実行するだけ」で、資料の写真ページが整う状態を目指したツールです。

---

## 何ができるか

入力：患者1人分の写真フォルダを2つ（**初診時** と **現在**）用意するだけ。

出力（`--out` フォルダに保存）：

| ファイル | 内容 |
|---|---|
| `01_コラージュ_初診時.png` | 8枚法の規格コラージュ（初診時） |
| `02_コラージュ_現在.png` | 8枚法の規格コラージュ（現在） |
| `03_比較_口腔内.png` | 口腔内5枚の Before / After 比較 |
| `04_比較_顔貌.png` | 顔貌3枚の Before / After 比較 |
| `確認シート_初診時.png` | AI判別＆向き補正の結果一覧（**目視確認用**） |
| `確認シート_現在.png` | 同上（現在） |
| `保定オリエンテーション_◯◯.pptx` | 編集できる PowerPoint 資料 |
| `保定オリエンテーション_◯◯.pdf` | そのまま配布できる PDF 資料 |

### 自動で行う「反転・並び替え」

- **左右反転**：右側方・左側方の頬側面観（ミラー像 → 実像へ）
- **上下反転**：上顎・下顎の咬合面観（撮影ミラーの反射像 → 実像へ）
- **並び替え**：8枚を規格レイアウト（顔貌を左右、口腔内5枚を中央十字）へ自動配置

向きの補正ルールは AI が画像ごとに判断し、判断が無い場合は種類ごとの既定ルール
（`src/photo/views.py` の `DEFAULT_TRANSFORM`）を使います。

---

## 8枚法の種類

| キー | 種類 | 既定の補正 |
|---|---|---|
| `face_front` | 顔貌正面（安静） | なし |
| `face_smile` | 顔貌正面（スマイル） | なし |
| `face_profile` | 側貌 | なし |
| `occlusal_upper` | 上顎咬合面観 | 上下反転 |
| `occlusal_lower` | 下顎咬合面観 | 上下反転 |
| `intra_right` | 右側方面観 | 左右反転 |
| `intra_front` | 正面面観 | なし |
| `intra_left` | 左側方面観 | 左右反転 |

## 使い方

### 1. 準備（初回のみ）

```bash
pip install -r requirements.txt
```

AI自動判別を使う場合は Anthropic API キーを環境変数に設定します。

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

### 2. 写真を2フォルダに入れる

```
長野りかこ/
├── 初診時/   ← 初診時の規格写真（8枚程度）
└── 現在/     ← 現在の規格写真（8枚程度）
```

ファイル名は自由です（AIが内容から判別します）。

### 3. 実行

```bash
cd src
python -m photo.cli \
    --initial "../長野りかこ/初診時" \
    --current "../長野りかこ/現在" \
    --out "../長野りかこ/出力" \
    --patient "長野りかこ"
```

### 4. 確認

`確認シート_*.png` を開き、各写真の **種類** と **[補正済] の向き** が正しいか目視確認します。
問題なければ PDF / PPTX をそのまま使えます。

---

## 分類モード（`--mode`）

| モード | 説明 | API |
|---|---|---|
| `ai`（既定） | 画像内容からAIが自動判別。フォルダに入れるだけ | 要 `ANTHROPIC_API_KEY` |
| `filename` | ファイル名のキーワード（`occlusal_upper` 等）から判定 | 不要 |
| `order` | 撮影順が決まっている前提で順番に割当 | 不要 |

`order` モードの順番は `views.py` の `STANDARD_ORDER`、
`filename` モードのキーワードは `classify.py` の `_FILENAME_HINTS` を参照。

---

## カスタマイズ

- **資料の文面・価格**：`src/photo/template.py`（`DECK`）を編集
- **コラージュのレイアウト**：`src/photo/views.py` の `COMPOSITE_LAYOUT`
- **向き補正の既定ルール**：`src/photo/views.py` の `DEFAULT_TRANSFORM`
- **配色・キャンバスサイズ**：`src/photo/layout.py` 冒頭の定数

---

## 注意

- 患者写真をAI判別に使う場合、画像（縮小したJPEG）が Anthropic API へ送信されます。院内の取り扱い方針に従ってください。`--mode filename` / `order` を使えば送信なしで処理できます。
- AI判別は完璧ではありません。**必ず確認シートで目視チェック**してください。誤判別があった場合はファイル名でヒントを付けて `--mode filename` を使うか、写真を撮り直してください。
- PDF は LibreOffice 等に依存せず生成します（Pillow で各スライドを描画）。PPTX は PowerPoint / Keynote / Google スライドで編集できます。
