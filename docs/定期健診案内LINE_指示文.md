# 定期健診案内 LINE 一斉送信 指示文

LINE公式アカウントマネージャー（manager.line.biz / chat.line.biz）で、患者リストの人を検索し、定期健診の案内を送るための指示文です。
「前日リマインドLINE」と同じ運用ルールで使えます。

---

## 依頼内容

このリストの人たちを **隣のタブの LINE のチャット** で検索して、下記の定型文を LINE で送ってください。

**送信を始める前に、まず「送信者リスト」を提示して確認を取ってください。**（詳しくは「進め方」の手順1を参照）

---

## 送信するメッセージ（このまま・変更しない）

```
🦷ステラ歯科からのお知らせ🦷

お口の調子はいかがでしょうか？

６月が定期健診の時期になりました！

お口の状況をチェックして、虫歯や歯周病を予防し歯を長持ちさせましょう✨

ご都合がよろしいお日にちをご予約お願い致します！
```

- **企業・法人アカウントなども含め、誰に対しても内容は一切変えずに、このまま送信** してください。
- 文面の追記・省略・絵文字の変更はしないでください。

---

## 検索ルール

0. **対象はリスト全員。** アポツールの連絡手段が LINE に設定されていない人も含め、**LINE で連絡できるかどうかに関わらず、全員を LINE で検索して送る**。連絡手段の設定で対象から外さないこと。
1. **患者番号が１〜３桁の人**
   - まず **患者番号** で検索する。
   - 患者番号で出てこなかったら **「番号＋名字」** で検索する。
2. それ以外（４桁以上 等）は、リストの表記に従って検索する。
3. 同名・複数ヒットで本人が特定できない場合は、送信せずに **指示を待つ**。

---

## 送らずに「指示待ち」にするケース

以下に当てはまる相手には **送信せず、リストに印を付けて指示を待って** ください。

- 現在 **やり取りの途中**（直近で会話が続いている、返信待ちがある等）の相手
- **確認が必要そう** な相手（個別事情・要対応メモがある、トラブル対応中 など）
- 検索しても **本人を特定できない**（ヒットなし／複数ヒットで判別不可）

> 迷ったら送らない。後で「この人どうしますか？」とまとめて確認してください。

---

## 進め方

1. **【最初に】送信者リストを提示して確認を取る。**
   - リストの全員を、これから送る順番で一覧にして提示する。
   - 各人について、検索ルールで特定した結果と、送る／保留の判定も付ける。
     （例：「12 田中 → 送信予定」「88 鈴木 → やり取り中のため保留」）
   - 「この内容・この対象で送信して大丈夫ですか？」と確認し、**OKをもらってから送信を開始する。**
2. リストの上から順に1人ずつ処理する。
3. 上記「検索ルール」で相手を特定する。
4. 「指示待ちケース」に該当しないか確認する。
   - 該当する → 送らずに保留リストへ。
   - 該当しない → 定型文をそのまま送信する。
5. 各人について結果を記録する（送信済み / 保留：理由）。
6. 全員ぶん終わったら、**送信件数** と **保留リスト（理由つき）** を報告する。
