# 業者連絡先一覧（博多ステラ歯科）

受付の名刺を「用途（何をしてほしいか）」で引けるようにまとめた一覧です。
**困ったときは、まずこのページを開いて該当カテゴリを探してください。**

> 使い方
> - 新しい業者が増えたら、該当カテゴリの表に1行追加する。
> - 名刺そのものは受付の名刺ホルダーにカテゴリ別で保管し、「名刺保管場所」欄にどのタブか書く。
> - 顧客番号・契約番号は故障連絡時にほぼ必ず聞かれるので、分かる範囲で必ず埋める。
> - 更新したら日付と担当者名を最終行のメモに残す。
