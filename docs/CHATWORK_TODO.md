# Chatworkで受付TODO

Chatworkの**マイチャット**（自分だけのチャット）に送った内容が、そのままTODOリストに貯まります。
新しいアカウントの作成も、SMS認証も必要ありません。すでに設定済みのChatworkトークンを使います。

```
Chatwork マイチャット
      │ メッセージを送る
      ▼
GitHub Actions（5分おき）
      │ 読み取り → 解釈
      ▼
data/todo.csv（台帳）
      │
      ▼
data/reception_todo.xlsx（月ごとのシート）
```

---

## 使い方

思いついたことを、マイチャットにそのまま送るだけです。**1通が1件**になります。

| 送る内容 | 登録されるもの |
|---|---|
| `物販コーナーのPOPを作り直す` | 受付からのタスク |
| `#院長 自費メニューの説明用紙を作る 8/25まで` | 種別＝院長から、期限＝8/25 |
| `在庫チェック #15分` | 目安時間＝15分 |
| `明日まで リコールはがきを出す`<br>`50枚くらい` | 期限＝明日、2行目以降はメモ |

### タグ

- `#院長` `#先生` → 院長からの依頼　/　`#受付` `#自分` → 受付から　/　`#定例` `#毎月` → 定例
- `#5分` `#15分` `#30分` → 空き時間の目安
- `今日まで` `明日まで` `8/25まで` `25日まで` → 期限

### コマンド

| 送る文字 | 動作 |
|---|---|
| `一覧` | 未完了を番号つきで表示 |
| `完了 12` | #12 を完了にする |
| `戻す 12` | #12 を未完了に戻す |
| `削除 12` | #12 を削除 |
| `ヘルプ` | 使い方を表示 |

番号は登録時とコマンドの返信に出る `#12` の数字です。並び替えても番号は変わりません。

---

## 始め方

1. リポジトリのSecretsに `CHATWORK_API_TOKEN` があることを確認（返信下書きの仕組みで設定済み）
2. このワークフローが動くのは**デフォルトブランチ（main）**です。作業ブランチにいる場合はマージしてください
3. GitHubの Actions タブ →「Chatwork TODO」→ **Run workflow** で初回実行
4. マイチャットに「受付TODOを開始しました」と案内が届く
5. 以降は、思いついたことを送るだけ

> **初回は過去のメッセージを取り込みません。** 3の実行時点より前のやり取りは無視され、
> それ以降に送ったものだけがタスクになります。

---

## 貯まったものを見る

| 見たいもの | 場所 |
|---|---|
| 今の未完了 | マイチャットで `一覧` と送る |
| 一覧をエクセルで | `data/reception_todo.xlsx`（月ごとのシート。GitHubからダウンロード） |
| 元データ | `data/todo.csv` |

エクセルは取り込みのたびに作り直されます。期限切れは赤、院長からは山吹色、完了は取り消し線です。
**このファイルを手で編集しても、次の取り込みで上書きされます。** 修正はマイチャットのコマンドで行ってください。

---

## 気をつける点

- **登録まで数分かかります。** GitHub Actions は5分間隔が最短で、混雑時はさらに数分遅れます
- **マイチャットは他の用途と混ぜないでください。** メモ書きもタスクとして登録されます
- 取り込み済みのメッセージは `data/todo_state.json` で管理しています。このファイルを消すと、
  直近100件が未処理として扱われ、二重登録になることがあります
- 自動返信は `[info]` の囲みで送られ、それ自体は取り込みの対象外です

## 仕組み

| ファイル | 役割 |
|---|---|
| `src/chatwork_todo.py` | 取り込みの本体。新着の判定、コマンド処理、返信 |
| `src/todo_parser.py` | 文面からタグ・期限・メモを読み取る |
| `src/todo_store.py` | CSV台帳の読み書き |
| `tools/build_todo_xlsx.py` | CSVからエクセルを生成 |
| `.github/workflows/chatwork-todo.yml` | 5分おきの実行と、結果のコミット |
