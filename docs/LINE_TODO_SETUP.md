# LINEで送るだけの受付TODO — セットアップ手順

LINE公式アカウントに思いついたことを送ると、Googleスプレッドシートに1行ずつ貯まる仕組みです。
受付PCからでも、自分のスマホからでも、同じLINEに送るだけで登録できます。

```
スマホ / PC の LINE
      │ メッセージ送信
      ▼
LINE公式アカウント（Messaging API）
      │ Webhook
      ▼
Google Apps Script（line-todo/Code.gs）
      │ 追記
      ▼
Googleスプレッドシート（月ごとのシート）
```

所要時間は30分ほどです。費用はかかりません（LINEの無料枠内）。

---

## かんたんセットアップ（推奨）

Google側（スプレッドシート作成・Apps Script設置・デプロイ）は、付属のスクリプトが自動で行います。
手作業は **LINEのチャネル作成** と **Google Cloudでの2つのAPI有効化**、そして認証画面で「許可」を押すことだけです。
所要10分ほど。うまくいかない場合は、下の「手動セットアップ」に進んでください。

### 手順1　LINE公式アカウントを作る（約7分）

1. https://developers.line.biz/console/ にLINEアカウントでログイン
2. プロバイダーを作成（例：博多ステラ歯科）
3. 「新規チャネル作成」→ **Messaging API** → チャネル名「受付TODO」で作成
4. 「Messaging API設定」タブで **チャネルアクセストークン（長期）** を発行してコピー
5. 同じタブで **応答メッセージ：オフ**、**Webhook：オン**
6. ページ下部のQRコードから、使う人全員が友だち追加

### 手順2　Googleの準備（約2分）

1. https://console.cloud.google.com/ で、Gmail連携に使っているプロジェクトを開く
2. 「APIとサービス」→「ライブラリ」から次の2つを有効化
   - **Google Apps Script API**
   - **Google Sheets API**
3. https://script.google.com/home/usersettings を開き、
   **「Google Apps Script API」をオン**にする

### 手順3　スクリプトを実行する（約1分）

リポジトリを手元に置いたPCで実行します。

```bash
pip install -r requirements.txt

export GMAIL_CLIENT_ID="（Gmail連携で使っているOAuthクライアントID）"
export GMAIL_CLIENT_SECRET="（同シークレット）"

python tools/setup_line_todo.py --token "手順1でコピーしたLINEのトークン"
```

ブラウザが開くのでGoogleアカウントを選び、「許可」を押します。
完了すると **Webhook URL** が表示されます。

### 手順4　LINEとつなぐ（約1分）

表示された Webhook URL を、LINE Developers の「Messaging API設定」→ **Webhook URL** に貼り付けて
「更新」→「検証」。成功と出れば、もうLINEに送るだけで登録されます。

### 手順5　使う人を限定する（あとからでOK）

1. 使う人それぞれがLINEで何か1通送る
2. 返信に出る **Uで始まるID** を全員分集める
3. 次を実行（Webhook URLは変わりません）

```bash
python tools/setup_line_todo.py --allow "U1a2b...,U9z8y..."
```

> `.line-todo-setup.json`（作成したシートやデプロイのID）と、実際のトークンが入った `Config.gs` は
> `.gitignore` に入れてあり、リポジトリにはコミットされません。

# 手動セットアップ

上のスクリプトを使わず、画面の操作だけで設定する場合はこちらです。

## 1. スプレッドシートを作る

1. https://sheets.google.com で新しいスプレッドシートを作成
2. 名前を「受付TODO」などに変更
3. URL の `/d/` と `/edit` の間の文字列（スプレッドシートID）を控える
   例：`https://docs.google.com/spreadsheets/d/`**`1AbC...xyz`**`/edit`

月ごとのシート（2026年8月 など）は、最初のメッセージが届いたときに自動で作られます。

---

## 2. LINE公式アカウントを作る

1. https://developers.line.biz/console/ にLINEアカウントでログイン
2. **プロバイダー**を作成（例：博多ステラ歯科）
3. 「新規チャネル作成」→ **Messaging API** を選択
4. チャネル名（例：受付TODO）、業種などを入力して作成
5. 作成後、次の2つを控える
   - 「Messaging API設定」タブ →**チャネルアクセストークン（長期）** を発行してコピー
   - 「チャネル基本設定」タブ → **チャネルシークレット**（今回は使いませんが控えておく）
6. 同じ「Messaging API設定」タブの下部
   - **応答メッセージ**：オフ
   - **あいさつメッセージ**：任意
   - **Webhook**：オン（URLは手順4で設定します）
7. ページ下部のQRコードから、使う人全員が**友だち追加**しておく

---

## 3. Apps Script を用意する

1. 手順1のスプレッドシートを開き、メニューの **拡張機能 → Apps Script**
2. 開いたエディタの `コード.gs` の中身を全部消し、このリポジトリの
   [`line-todo/Code.gs`](../line-todo/Code.gs) の内容を貼り付けて保存
3. 左メニューの **プロジェクトの設定（歯車）→ スクリプト プロパティ** で次を追加

   | プロパティ | 値 |
   |---|---|
   | `LINE_CHANNEL_ACCESS_TOKEN` | 手順2で発行したチャネルアクセストークン |
   | `SPREADSHEET_ID` | 手順1で控えたスプレッドシートID |
   | `ALLOWED_USER_IDS` | いったん**空のまま**（手順5で設定） |

---

## 4. デプロイして Webhook をつなぐ

1. Apps Scriptエディタ右上の **デプロイ → 新しいデプロイ**
2. 種類の選択（歯車）→ **ウェブアプリ**
3. 設定
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
     （LINEのサーバーから届くため、この設定が必要です）
4. デプロイ → 初回は権限の確認が出るので許可
5. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピー
6. LINE Developers の「Messaging API設定」→ **Webhook URL** に貼り付けて **更新**
7. 「検証」ボタンを押して成功すればつながっています

> コードを修正したときは、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新規作成 → デプロイ**
> で更新してください。URLは変わりません。「新しいデプロイ」を選ぶとURLが変わってしまいます。

---

## 5. 使う人を限定する（重要）

Apps Script のウェブアプリは、URLを知っていれば誰でもアクセスできます。
URLが漏れても他人が書き込めないよう、**送信できるLINEアカウントを限定**します。

1. 友だち追加した各自が、LINEで何かメッセージを1通送る
2. 「このアカウントはまだ登録されていません」という返信に**あなたのID**（`U` から始まる文字列）が出る
3. 全員分を集め、スクリプトプロパティ `ALLOWED_USER_IDS` にカンマ区切りで登録
   例：`U1a2b3c...,U9z8y7x...`
4. 保存すると、そのID以外からの登録は受け付けなくなります

`ALLOWED_USER_IDS` が空のあいだは、友だち追加した誰でも書き込める状態です。**必ず設定してください。**

---

## 6. 使い方

思いついたことを、そのままLINEに送るだけです。1通が1件になります。

| 送る内容 | 登録されるもの |
|---|---|
| `物販コーナーのPOPを作り直す` | 種別＝受付から、やること＝物販コーナーのPOPを作り直す |
| `#院長 自費メニューの説明用紙を作る 8/25まで` | 種別＝院長から、期限＝8/25 |
| `在庫チェック #15分` | 目安時間＝15分 |
| `明日まで リコールはがきを出す`<br>`50枚くらい` | 期限＝明日、2行目以降はメモ |

**タグ**

- `#院長` `#先生` → 院長からの依頼　/　`#受付` `#自分` → 受付から　/　`#定例` `#毎月` → 定例
- `#5分` `#15分` `#30分` → 空き時間の目安
- `今日まで` `明日まで` `8/25まで` `25日まで` → 期限

**コマンド**

| 送る文字 | 動作 |
|---|---|
| `一覧` | 今月の未完了を番号つきで表示 |
| `完了 12` | #12 を完了にする |
| `戻す 12` | #12 を未完了に戻す |
| `削除 12` | #12 を削除 |
| `ヘルプ` | 使い方を表示 |

番号はスプレッドシートの行番号です。スプレッドシート側で行を削除すると番号がずれるので、
削除はLINEの `削除` コマンドか、行の削除後に `一覧` で番号を取り直してください。

---

## 7. 毎朝リマインドする（任意）

朝に未完了の一覧をLINEに届けたい場合：

1. Apps Scriptエディタ左メニューの **トリガー（時計アイコン）→ トリガーを追加**
2. 実行する関数：`daily`
3. イベントのソース：**時間主導型** → 日付ベースのタイマー → 午前8時〜9時
4. 保存

`ALLOWED_USER_IDS` に登録した全員に届きます。

---

## 8. エクセルで見たいとき

スプレッドシートのメニューから **ファイル → ダウンロード → Microsoft Excel (.xlsx)** で
いつでもエクセル形式に書き出せます。チェック欄・期限切れの色分けもそのまま残ります。

---

## うまく動かないとき

| 症状 | 確認すること |
|---|---|
| 返信が来ない | LINE Developers の Webhook が「オン」か。「検証」が成功するか |
| 「エラーが起きて登録できませんでした」 | Apps Script の**実行数**（左メニュー）でエラー内容を確認。多くは `SPREADSHEET_ID` の誤り |
| 応答メッセージが二重に来る | LINE Developers の「応答メッセージ」をオフにする |
| コードを直したのに反映されない | 「デプロイを管理」から**新しいバージョン**でデプロイし直す |
| 登録されませんと言われ続ける | `ALLOWED_USER_IDS` のIDに余分な空白や改行が入っていないか |

---

## 仕組み上の注意

- Apps Script のウェブアプリはリクエストヘッダーを読めないため、LINEの署名検証（`X-Line-Signature`）が
  行えません。かわりに**URLの秘匿**と **`ALLOWED_USER_IDS` による送信者の限定**で守っています。
  URLは院内の関係者以外に共有しないでください。
- LINEの無料プランでは、こちらから送るメッセージ（毎朝のリマインドなど）に月あたりの上限があります。
  返信（`reply`）は上限の対象外です。
