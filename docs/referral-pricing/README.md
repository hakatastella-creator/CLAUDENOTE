### 矯正（インビザライン）— 定価据え置き ＋ 矯正検査診断料 44,000円 無料

パッケージ価格は1円も下げない。かわりに検査診断料 44,000円（税込）を無料にする。

理由：矯正の粗利率は定価でも 64〜76% と低く、値引きの余地がそもそも小さい。
一方で検査診断料はアラインへの支払いがゼロ＝丸ごと利益なので、
**医院の持ち出しを一切出さずに「44,000円分お得」を提示できる**。
（元データ『矯正_値引き価格表』A25 の方針をそのまま採用）

## 医院の実質コストの考え方

ここが今回いちばん大事な論点。**患者さんから見た「お得額」と、医院が新たに失う額は一致しない。**

紹介がなくても本数に応じた割引は出していたので、通常割引との差額だけが本当のコスト：

| ケース | 通常出していた割引 | ロイ紹介 | 医院の実質負担 |
|---|---|---|---:|
| 1〜2本 | 10%OFF | 20%OFF | 定価の 10% |
| 3〜5本 | 10%OFF | 20%OFF | 定価の 10% |
| 6〜9本 | 15%OFF | 20%OFF | 定価の 5% |
| 10本以上 | 20%OFF | 20%OFF | **0円** |
| 矯正 1件 | 値引きなし | 検査診断料無料 | 44,000円 |

負担が出るのは小さい症例のほうで、**大きい症例ほど医院の追加負担は減り、10本以上ではゼロ**。
xlsx の「損益分岐シミュレーション」シートに、症例パターン別の実質負担と
「月に何件までなら従来の月額紹介料より安いか」を計算する表を入れてある。

**この切り替えの本質は、紹介料が固定費から変動費に変わること。**
紹介がゼロの月の負担は、従来＝月額まるごと／新方式＝0円。
負担が出るのは必ず売上が立ったときだけで、しかも粗利率65%以上は必ず残る。

- [ ] **適用範囲** — 在籍スタッフ本人のみか、同伴者も含むか。曖昧にすると際限なく広がる
- [ ] **月間の値引き上限** — 例：月20万円分まで。無制限にすると値引き総額が青天井になる
- [ ] **有効期限** — 例：初回6か月、以降は実績を見て更新。無期限にすると紹介が止まっても価格だけ残る
- [ ] **紹介の確認方法** — 紹介カード or ロイ様からのLINE提示。口頭申告だけだと後から検証できない
- [ ] **ロイ様個人には現金が入らなくなる点の合意** — ここが合意できないと制度が続かない

## 注意点

- **自費診療のみが対象。** 保険診療の一部負担金は法令上、値引き・免除ができない
- 患者紹介の対価として金銭を継続的に支払う形（従来の月額紹介料）は、自費診療であっても
  患者紹介ビジネスとして問題視されうる論点がある。値引きへの切り替えは、その意味でも合理的。
  ただし最終的な適法性の判断は顧問弁護士・顧問税理士に確認すること
- 会計処理が「紹介料（費用計上）」から「売上値引（売上の減額）」に変わるので税理士に共有する
- 前歯レイヤリングの連冠は技工料が1歯につき +2,000円。スーパーエナメル6本連冠を20%OFFすると
  粗利率 63.4% まで下がる（全ケースで最低）
- ホワイトニング・インプラント等は元データに原価情報がないため未掲載
