# デンタルローン お支払い早見表

患者さんへの分割払いのご説明用シミュレーターです。治療費を入力すると、回数ごとの
月々のお支払い額・分割払手数料・総お支払い額が一覧で表示されます。

## 使い方

`index.html` をブラウザで開くだけで動きます（インストール・通信設定は不要）。
タブレットやカウンセリングルームのモニターでそのままお見せいただけます。

- **治療費（税込）** — 金額を入力。よく使う金額はボタンでも入力できます
- **頭金** — 頭金がある場合に入力すると、残額のみで分割計算します
- **実質年率** — 初期値はアプラスの 5.8%。条件が変わった場合はここを変更します
- **回数タイル** — タップすると、右側に内訳（初回・2回目以降・手数料・総額）が出ます
- **月々のご予算から逆算** — 「月々1万円まで」というご希望から、治療費の目安を逆算します

年率と選択中の回数はブラウザに記憶されるため、次回も同じ設定で開きます。
`Ctrl / ⌘ + P` で印刷すると、入力補助ボタンや逆算欄を省いた形で印刷できます。

## 計算方法

元利均等方式（アドオンではなく残債方式）で算出しています。

```
月利 r = 実質年率 / 100 / 12
毎月の支払額 = 分割対象額 × r / (1 − (1 + r)^−回数)
お支払い総額 = round(毎月の支払額 × 回数)
分割払手数料 = お支払い総額 − 分割対象額
2回目以降    = floor(お支払い総額 / 回数)
初回         = お支払い総額 − 2回目以降 × (回数 − 1)   ← 端数調整
```

あくまで概算です。実際のお支払い金額・回数・手数料は株式会社アプラスの審査結果
およびご契約内容により決定されます。ボーナス併用払いには対応していません。
