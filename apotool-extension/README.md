# ステラ 月次レポート出力（アポツール用 Chrome拡張）

> ⚠️ **非推奨**：アポツールで拡張機能が使えなくなる見込みのため、この方式は使えなくなります。
> 今後は入力フォーム型の [`monthly-report-builder/`](../monthly-report-builder/README.md) をお使いください。
> （このフォルダは記録として残しています）

アポツールの画面から月次のKPIを取り込み、**Excel（.xlsx）の月次レポート**を1クリックで書き出す Chrome / Edge 拡張機能です。

アポツールには（診療カレンダーのExcelダウンロードを除いて）データの書き出し機能が無いため、既存の LINE用拡張と同じく **画面に表示されている集計値をそのまま読み取る方式** で作っています。

> **患者の個人情報は取り込みません。** 電話番号・氏名・生年月日らしきテキストは読み取り段階で除外し、扱うのは集計値とラベルのみです。

## このシートの位置づけ（自動抽出できるものだけ）

アポツールで**自動で取れる「件数・率・人数」だけ**を1枚にまとめた月次シートです。
**売上金額（保険点数・自費総額・矯正売上・合計・スタッフ別・メニュー別金額）はアポツールに無い**ため含みません。
金額系はレセコン・会計から別途、従来どおり手入力してください。

## 取り込める画面と主なデータ

| 画面 | URL | 取り込む主な項目 |
|---|---|---|
| ② クリニックデータ | `/user/dashboard/` | キャンセル率・無断キャンセル・種別キャンセル・予約取得率(AP取得率)・来院率・定期検診来院率・本来対象者数・当月治療中断/リコール中断・中断率・リコール率・総予約件数・来院人数 |
| ③ 全ての予約 | `/user/patient/reservation` | 今月の予約総数・区分別件数（自費/Cure/Care）・Web予約件数 |
| ④ イベント | `/user/event/` | 矯正の診療ステップ件数（相談・検査・説明・契約・保定 ほか） |

### 自動計算する指標（件数から算出）

画面の率表示に頼らず、取り込んだ件数から拡張側で計算して出力します。

- **相談→検査率** ＝ 検査 ÷ 相談
- **矯正成約率** ＝ 契約 ÷ 相談
- **当月中断合計** ＝ 治療中断 ＋ リコール中断

## インストール（5分）

1. この `apotool-extension` フォルダを PC の任意の場所に用意する
   （リポジトリを ZIP ダウンロードして解凍 → `apotool-extension/` を取り出す、でOK）
2. Chrome で `chrome://extensions` を開く
3. 右上の **「デベロッパーモード」** を ON
4. **「パッケージ化されていない拡張機能を読み込む」** → `apotool-extension` フォルダを選択
5. 一覧に「ステラ 月次レポート出力（アポツール）」が出れば完了

> **ドメインを絞りたい場合**：初期設定では `https://*/user/*` の全サイトでパネルが出ます。アポツールだけに限定したいときは `manifest.json` の `matches` を
> `"https://あなたのアポツールのドメイン/user/*"` に書き換えてください。

## 使い方（毎月の作業）

1. アポツールにログインし、**②クリニックデータ** を開く
2. 画面右上の緑パネル **「🗓 月次レポート出力」** で、**対象月**を確認（初期値は今月）
3. **「🔍 画面から自動取り込み」** をクリック
   - 拾えた項目が下のリストに入る → **内容を確認・手直し**（不要な行は ✕、足りない行は「＋行」）
   - うまく拾えない時は **「貼り付けて解析」** を開き、画面のKPI部分をドラッグ選択してコピー→貼り付け→解析
4. **「💾 この画面を保存」** をクリック
5. **③全ての予約**、**④イベント** でも 3〜4 を繰り返す
6. どの画面からでも **「📊 Excel出力（まとめて）」** をクリック
   → `月次レポート_YYYY-MM_博多ステラ歯科.xlsx` がダウンロードされる

保存データは対象月ごとにブラウザ内（`chrome.storage.local`）に残るので、
途中まで取り込んで後で続きをやってもOKです。作り直したい月は **「🗑 今月分を消去」**。

## 補足・制約

- アポツールは画面ログインが前提のため、GitHub Actions等での**完全自動化はできません**（＝毎月ボタンで実行する半自動運用）。
- 自動取り込みは画面レイアウトに依存するヒューリスティックです。**取り込んだ値は必ず画面と突き合わせて確認**してください（貼り付け解析＋手直しでどんな画面でも確実に作れます）。
- 診療カレンダーの明細が必要な場合は、アポツール標準の「Excelダウンロード」をそのままご利用ください。
