✨ 設定

console.anthropic.com で発行したキー。
ローカルにのみ保存され、外部に送信されません。

📄 料金表画像の登録

各プランの料金表画像（PNG / JPG）を登録すると、LINE画面のパネルの
ボタン1つでコピーできます。画像はこのPC内にのみ保存されます。
返信下書きの使い方
1. LINE Official Account Manager または chat.line.biz を開く
2. 画面右上のパネルで「📋 画面から会話を読み取る」
3. 「✨ 下書きを生成」
4. 「▶ 入力欄に挿入」または「📋 コピー」

料金表の送り方
1. 上で各プランの料金表画像を登録
2. LINE画面のパネルで「① インビザラインフル…」等を押す
3. LINEの入力欄をクリックして Ctrl+V（貼り付け）
4. 送信ボタンで送る
