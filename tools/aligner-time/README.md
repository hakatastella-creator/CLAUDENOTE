# アライナー チェアタイム計算

矯正のアライナーが届いたときに、次回来院の所要時間（予約枠）を出すツールです。
`index.html` を開くだけで動きます（インストール不要。Artifact として公開した場合は設定を医院内で共有できます）。

## 使い方

1. 来院の種類を選ぶ（基本・追加アライナー／保定リテーナー）
2. クリンチェックを見て入力する
   - アタッチメント除去：個数
   - アタッチメントセット：口腔マップ（6分割）でブロックを選択
   - ボタン除去：口腔マップでブロックを選択
   - ボタンセット：個数
   - IPR：か所数
3. 上部に「予約枠」が出る（「分数をコピー」で LINE の定型文に貼り付け）

保定（リテーナー）を選ぶと、アタッチメント除去に「ドクター」の印が付き、
予約枠のうちドクターが対応する時間が表示されます。

## 時間の計算

口腔を6ブロック（上下 × 右臼歯・前歯・左臼歯）に分けて考えます。

| 処置 | 数え方 | 初期値 |
| --- | --- | --- |
| アタッチメント除去 | 個数で段階 | 1〜4個：15分／5個以上：30分 |
| アタッチメントセット | ブロック | 7.5分／1ブロック（臼歯のみ4ブロック=30分・全体6ブロック=45分） |
| ボタン除去 | ブロック | 7.5分／1ブロック |
| ボタンセット | 個数 | 5分／1個 |
| IPR | か所数で段階 | 1〜5か所：15分／6か所以上：30分 |
| 基本（お渡し・チェック・説明） | 固定 | 0分（必要なら設定で加算できます） |

```
所要時間 = 基本時間（来院の種類で切替）+ アタッチメント除去 + IPR + 各ブロック合計 + 個数×単価
予約枠   = 所要時間を15分単位で切り上げ（最短15分。処置が何もなければ0分）
```

すべての値は画面の「時間の設定」から変更できます。

## 受付PCに置いて使う

`standalone/アライナー時間計算.html` を受付PCのデスクトップ（受付フォルダ）に保存し、
ダブルクリックで開きます。ショートカットをデスクトップに作っておくと早いです。

- インターネットに繋がっていなくても動きます（フォントだけ標準のものに変わります）
- 設定はそのPCのブラウザに保存されます（PCごとに設定が必要）
- ファイルは `index.html` から生成しています。中身を直したら次のコマンドで作り直してください。

```
python3 tools/aligner-time/build_standalone.py
```

## 設定の保存先

- Artifact として公開している場合: 保存するとスタッフ全員に共有されます（`db` 機能）
- ファイルを直接開いている場合: その端末のブラウザにのみ保存されます
