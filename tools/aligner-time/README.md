# アライナー チェアタイム計算

矯正のアライナーが届いたときに、次回来院の所要時間を出して、患者さんへの連絡文まで作るツールです。
`index.html` を開くだけで動きます（インストール・通信なし。Artifact として公開した場合は設定を医院内で共有できます）。

## 使い方

1. クリンチェックを見て、処置の数を入れる
   - アタッチメント除去 / アタッチメントセット / ボタン除去 / ボタンセット / IPR
2. 上部に「予約枠」が出る
3. 患者さんのお名前を入れて「本文をコピー」→ LINE やメールに貼り付け

## 時間の計算

```
所要時間 = 基本時間 + Σ（処置の数 × 1件あたりの時間）
予約枠   = 所要時間を丸め単位で切り上げ（最短の予約枠を下回らない）
```

初期値（すべて画面の「1件あたりの時間の設定」で変更できます）:

| 項目 | 初期値 |
| --- | --- |
| 基本（お渡し・チェック・説明） | 10分 |
| アタッチメント除去 | 2分／1個 |
| アタッチメントセット | 3分／1個 |
| ボタン除去 | 1分／1個 |
| ボタンセット | 2分／1個 |
| IPR | 3分／1か所 |
| 予約枠の丸め | 10分単位 |
| 最短の予約枠 | 15分 |

この初期値は一般的な目安です。実際の診療に合わせて調整してください。

## 設定の保存先

- Artifact として公開している場合: 保存するとスタッフ全員に共有されます（`db` 機能）
- ファイルを直接開いている場合: その端末のブラウザにのみ保存されます
