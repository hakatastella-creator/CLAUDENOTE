# 月次レポート作成システム（入力フォーム型）

アポツールの画面を見ながら**数字を入力するだけで月次Excel（.xlsx）を作る**、単一HTMLのシステムです。

- **ブラウザ拡張もインストールも不要**。`index.html` をダブルクリックで開くだけ。
- **オフラインで動作**。アポツールの仕様変更に一切左右されません。
- 合計売上高・中断合計・転換率などは**自動計算**。
- 入力内容はこの端末のブラウザ内に**対象月ごとに自動保存**（外部送信なし）。

> 旧「アポツール用 Chrome拡張（`apotool-extension/`）」は、アポツールで拡張機能が使えなくなる見込みのため**非推奨**です。今後はこの入力フォーム型をお使いください。

## 使い方

1. `monthly-report-builder/index.html` を PC に保存
   （リポジトリを ZIP ダウンロード → 解凍 → このファイル、でOK）
2. ファイルを**ダブルクリック**してブラウザで開く
3. 上部で **対象月** を選ぶ
4. アポツールの画面を見ながら、各欄に数字を入力
   - **① 来院・診療実績**（一般・審美／矯正）
   - **② 売上（円）** … 合計売上高は自動計算
   - **③ リコール** … 中断合計は自動計算
   - **④ 自費分類（流入経路）** … 一般・審美／矯正、合計は自動計算
   - **⑤ その他**（口コミ数）
5. **「📊 月次Excelを作成してダウンロード」** をクリック → `月次報告_YYYY-MM_医院名.xlsx` が保存される

### 便利機能

- **💾 一時保存** … 途中まで入力して後で続ける
- **📂 先月を複製** … 先月の入力を今月にコピー（数字だけ直せば完成）
- **🗑 クリア** … 今月の入力欄を空にする（保存済みデータは残る）

## 自動計算される項目

| 項目 | 計算式 |
|---|---|
| 合計売上高 | 保険点数 ＋ 自費総額 ＋ 雑収入 ＋ 美容売上 |
| 相談→検査率 | 検査 ÷ 相談 |
| 矯正成約率 | 契約 ÷ 相談 |
| 当月中断合計 | 治療中断 ＋ リコール中断 |
| 自費分類 合計 | 各流入経路の合計（一般・審美／矯正それぞれ） |

## 補足

- まずは**主要ブロック**（来院実績・売上合計・リコール・自費分類）の構成です。
  スタッフ別売上・自費メニュー別（矯正グレード／補綴／美容 等）・レセプト統計などの
  細かい内訳は、必要になったら入力欄を追加できます。
- 患者の個人情報は扱いません（入力するのは集計値のみ）。
