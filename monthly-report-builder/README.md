# 月次レポート作成システム（入力フォーム型）

アポツールの画面を見ながら**数字を入力するだけで月次レポートを作る**、単一HTMLのシステムです。
入力項目は**アポツールの画面（クリニックデータ）に表示される内容**に合わせてあり、
画面を見て転記するだけで完成します（拡張機能・データ抽出は不要）。

- **ブラウザ拡張もインストールも不要**。`index.html` をダブルクリックで開くだけ。
- 📸 **スクショから自動入力（OCR）**。レセコン／アポツールの画面のスクショを貼るだけで、
  数字を読み取ってフォームに自動入力（**画像はこの端末内だけで処理・外部送信なし**）。誰でも操作できます。
- キャンセル率・自費率・定期検診の各率・転換率などは、**件数を入れれば自動計算**。
- 入力内容はこの端末のブラウザ内に**対象月ごとに自動保存**（外部送信なし）。
- **「レポートを表示」でKPI・表・グラフに整形** → そのまま印刷・PDF保存できます。
- データ受け渡し用に **Excel（.xlsx）出力**も可能。

> ⚠️ OCRの初回だけ、読み取りエンジンの取得にインターネット接続が必要です（以降は端末にキャッシュ）。手入力だけならオフラインでも動作します。

## 📸 スクショから自動入力（OCR）の使い方

1. `index.html` を開く（対象月を選ぶ）
2. **「📸 スクショから自動入力」** の枠に、レセコン／アポツールの画面のスクショを
   **ドラッグ**、または **Ctrl+V で貼り付け**（複数枚まとめてOK）
3. **「🔎 読み取って自動入力」** を押す → 数字が下のフォームに自動で入ります
4. 枠の下に **「読み取り結果」** が出るので、**スクショと見比べて金額をサッと確認**（違えば直す）
5. あとは通常どおり **「🖨 レポートを表示」** → 印刷/PDF、または **「📊 Excelを作成」**

**対応画面と自動で埋まる項目**

| スクショ（画面） | 自動で埋まる項目 |
|---|---|
| レセコン「個人別（サマリー）」 | 来院人数・新患・再初診・再診・自費来院→自費件数・保険来院→保険件数・合計保険点数→保険点数（×10） |
| レセコン「自費項目別」 | 矯正／美容／自費の各項目の **件数＋金額**（項目名で自動振り分け） |
| レセコン「販売品目別」 | 物販（販売品目）の **件数＋金額**（合計行） |
| アポツール「クリニックデータ」 | キャンセル率・リカバリー率・予約未定者・リコール・リコオリ（読める範囲で） |

- 読み取りは **100%ではありません**（特に小さい表・薄い文字）。**金額は必ず目視で確認**してください。
  スクショは**大きく・鮮明**（画面を最大化して撮る）ほど精度が上がります。
- うまく振り分けられなかった行は「**未割当・手入力してください**」と表示されるので、その項目だけ手で入れてください。
- 「入力済みも上書きする」に✓を入れると、既に入っている欄もOCRの値で上書きします（既定はオフ＝空欄だけ埋める）。

> 旧「アポツール用 Chrome拡張（`apotool-extension/`）」は、拡張機能が使えなくなる見込みのため**非推奨**です。

## 入力項目と「取得の手間」（受付向け）

各セクションに、受付が数字をどう用意するかのバッジを付けています。

- 🟢 **一目**：アポツールの画面が集計済み。転記するだけ（数秒）。
- 🟠 **要カウント**：集計表示が無ければ検索して数える（少数・重要なものだけ）。
- 🔵 **手入力**：アポツール外（会計・レセコン）から。

| セクション | 取得 | 入力項目 |
|---|---|---|
| クリニックデータ（予約・来院） | 🟢 | 総予約件数・来院人数・予約未定者（矯正以外） |
| クリニックデータ（初再診内訳） | 🔵 | 新患・再初診・再診（レセコン個人別サマリー） |
| クリニックデータ（キャンセル） | 🟢 | 事前／当日／無断キャンセル・キャンセル後1M以内来院率 |
| クリニックデータ（自費・保険 件数） | 🟢 | 自費件数・保険件数 |
| クリニックデータ（定期検診） | 🟢 | 対象者数・予約者数・来院数・定期検診来院率 |
| クリニックデータ（中断） | 🟢 | 中断患者数 |
| 矯正パイプライン | 🟠 | 患者ごとに **氏名＋ステージのチェック**（検査／説明予約／治療計画説明／支払／開始）。人数は自動集計 |
| 売上 | 🔵 | 保険点数／**矯正**(フル・モデレート・ライト・エクスプレス・矯正検査・プレオルソ・リテーナー)／**美容**(ハイフ・ホワイトニング)／**自費**(ジルコニアインレー・セラミックインレー・ジルコニアクラウン・オールセラミックス・ジルコニアBr・ボトックス・ダイレクトボンディング・スーパーエナメル・その他)／キャンセル料・物販（販売品目）。**各項目に「件数」＋「金額」**を入力（レセコンの数量＝件数） |

> 🟠 矯正は月をまたいで進む（7月に説明→8月に開始 など）ため、**割合(%)は出しません**。代わりに
> **患者ごとのステージ管理**にしています。検査→説明予約→治療計画説明→**支払**→（発注・到着）→**開始** の流れを
> チェックで記録し、「説明済・未支払」「支払済・未開始（＝発注〜到着待ち）」の人数も自動で出るのでフォロー漏れを防げます。
> 「📂 先月を複製」で先月のパイプラインを引き継ぎ、進んだ人のチェックを更新していく運用が便利です。

## 自動計算される項目

| 項目 | 計算式 |
|---|---|
| 矯正 売上計 | フル＋モデレート＋ライト |
| 美容 売上計 | ハイフ＋ホワイトニング |
| 自費 売上計 | ジルコニア＋セラミック＋ラミネート＋ダイレクトボンディング＋ボトックス＋その他 |
| 自費総額 | 矯正計＋美容計＋自費計＋キャンセル料 |
| 合計売上高 | 保険点数＋自費総額＋物販（販売品目） |
| キャンセル率 | （事前＋当日＋無断）÷ 総予約件数 |
| 自費率 | 自費件数 ÷（自費件数＋保険件数） |
| 定期検診 予約取得率 | 予約者数 ÷ 対象者数 |
| 定期検診 来院率 | 来院数 ÷ 予約者数 |
| 矯正 各ステージ人数 | 検査／説明予約／説明／支払／開始 のチェック数 |
| 説明済・未支払 | 説明✓かつ支払✗の人数 |
| 支払済・未開始（発注〜到着待ち） | 支払✓かつ開始✗の人数 |

## 使い方

1. `monthly-report-builder/index.html` を PC に保存（リポジトリを ZIP ダウンロード → 解凍）
2. ファイルを**ダブルクリック**してブラウザで開く
3. 上部で **対象月** を選ぶ
4. アポツールの各画面を見ながら、対応する欄に数字を入力（率は自動で埋まります）
5. **「🖨 レポートを表示」** → KPI・表・グラフの月次レポートが表示される
   → **「🖨 印刷 / PDFで保存」** で、A4のPDFとして保存・共有（ブラウザの印刷で「PDFに保存」を選択）
6. データを他で使う時は **「📊 Excelを作成」** → `月次レポート_YYYY-MM_医院名.xlsx`

### レポートに載る内容

- **KPIカード**：合計売上高／総予約件数／キャンセル率／矯正開始
- **売上**（内訳表＋カテゴリ別グラフ＋矯正内訳グラフ＋自費内訳グラフ）
- **予約・来院／初再診・キャンセル**（予約・来院＋初再診内訳（新患・再初診・再診）＋キャンセル＋自費保険）
- **矯正パイプライン**（患者ごとのステージ表＋ステージ別人数グラフ＋フォロー漏れ人数）
- **定期検診（リコール）**（表＋リコールファネル）
- **中断**（中断患者数）

### 便利機能

- **💾 一時保存** … 途中まで入力して後で続ける
- **📂 先月を複製** … 先月の入力を今月にコピー（数字だけ直せば完成）
- **🗑 クリア** … 今月の入力欄を空にする（保存済みデータは残る）

## 補足

- 患者の個人情報は扱いません（入力するのは集計値のみ）。
- 患者ランクの区分（S/A/B/C/なし）やイベントのメニュー名は、実際のアポツール表記に合わせて
  `index.html` の `SECTIONS` を編集すれば変更できます。
