博多ステラ歯科のCLAUDENOTE

## 毎日の返信下書き自動生成

Gmail と Chatwork の未読メッセージを毎朝チェックし、過去のやり取りから相手ごとの文体を学習した返信下書きを自動生成します。

- **Gmail**: 下書きフォルダに直接保存
- **Chatwork**: サマリーメールにまとめて自分宛に送信
- **実行**: GitHub Actions で毎朝 7:00 JST（変更可）
- **対象**: 個人からの未読のみ（自動配信は除外）
- **学習元**: その相手との直近10件のやり取り

セットアップ手順は [`docs/SETUP.md`](docs/SETUP.md) を参照。

## Google口コミ・プレゼント台帳

月例ミーティングで共有する Google 口コミの一覧です。口コミを書いた患者番号・氏名・内容と、
プレゼント（矯正中はホワイトニング／矯正以外は物品1,000円OFF）を渡したかどうかを 1 画面で管理します。

- **ソース**: [`google-reviews/index.html`](google-reviews/index.html)（1ファイル完結の Web ページ）
- **共有**: Artifact として公開し、リンクを開いた人が同じリストを見て更新できます
- **主な機能**: 月ごとの切り替え／未渡し・渡し済の絞り込み／区分に応じたプレゼントの自動判定／
  ミーティング用の共有モード（文字を大きく表示）／印刷・テキストコピー・CSV書き出し
