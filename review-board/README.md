# 口コミ御礼台帳

Google口コミを書いてくださった患者さんと、お渡しするプレゼントの進捗をまとめる共有ページ。
毎月のミーティングで、この画面をそのまま共有して使う。

- 患者番号 / 氏名 / 投稿日 / 星の数 / 口コミ本文 / 備考メモ を登録
- 「矯正中 → ホワイトニング」「矯正なし → 物品1,000円OFF」をチェックひとつで自動判定
- 「未お渡し ⇄ お渡し済み」はボタンひと押しで切り替え、全員の画面に反映
- 対象月の切り替え、未お渡しだけの絞り込み、番号・氏名・本文の検索
- LINE / チャットワークに貼れる「コピー用テキスト」と、印刷用レイアウト

公開先（Artifact）: https://claude.ai/code/artifact/1f00778f-6e98-469c-b91c-17be46b7c9c9

## ファイル

| ファイル | 中身 |
| --- | --- |
| `template.html` | ページ本体。編集するのはこのファイルだけ |
| `build.py` | `template.html` から公開用の `index.html` を組み立てる |
| `index.html` | 公開したもの（生成物・直接編集しない） |
| `full.html` | ブラウザで直接開いて確認するための完全な HTML（`--full` 指定時のみ生成） |

## 更新のしかた

```bash
python3 build.py          # index.html を作り直す
python3 build.py --full   # 動作確認用の full.html も作る
```

そのうえで、同じ URL の Artifact へ `index.html` を再公開する。

## 仕組み

台帳のデータはページ自身の中に JSON（`<script id="app-state">`）として入っていて、
チェックや追加をするたびに、ページが自分自身を新しいバージョンとして保存し直す
（Artifact の `artifact` capability）。サーバーもデータベースも要らない代わりに、
ページは「自分の作り方」を知っている必要があるため、`template.html` の全文を
`<script id="page-source" type="text/plain">` に入れ子で持たせている。
`build.py` がその入れ子を作る。

そのため `template.html` には次の決まりがある（`build.py` が起動時に検査する）。

- `%%STATE%%` と `%%SELF%%` がそれぞれちょうど 1 つ
- 閉じタグ以外の場所に `</script` という並びを書かない
- 逃がした形の `<\/script` も書かない

書き込み権限がない人が開いたときは、変更をその端末の localStorage に保存し、
「閲覧のみの権限です」と表示する（他の人には反映されない）。
