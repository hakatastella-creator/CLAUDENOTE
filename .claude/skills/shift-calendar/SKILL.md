# シフト表CSV → カレンダー

毎月、アポツールから書き出したシフト表CSVが届くので、医院の従来のカレンダー形式（月〜日、1日1マス）の Excel にする。

## 手順

1. CSVを専用の空ディレクトリにコピーし、変換する:
   ```
   python3 shift-calendar/make_calendar.py <コピーしたCSV> <出力先>/YYYY年M月シフト表.xlsx
   ```
   スクリプトは書き出し後に Excel を読み戻して、CSVと1人×1日ずつ照合する。「照合OK … 食い違い0件」が出なければ渡さない。
2. 目でも確認する: 一時コピーを1ページに収まる横向き印刷設定（print_area `B2:O16`、fitToPage）にして `soffice --headless --convert-to pdf` → `pdftoppm -png` で画像にして見る。文字が切れていないか、数日分をCSVと突き合わせる。元ファイルの印刷設定は変えない。
3. できた xlsx をユーザーに送る（SendUserFile）。

## 変換ルール（ユーザーと決めたもの）

- フ＝名前のみ、A＝名前＋AM、P＝名前＋PM、休＝書かない
- 1マス3段: 歯科医 / 衛生士 / 助手（CSVの見出し順）。同じ段は「・」区切り、CSVの行順
- 名前はCSVのまま、先頭の DR/DH/DA だけ外す（「院長」「城戸美景」もそのまま）
- 「担当希望なし」の行は使わない。「口腔外科医」の行は出勤日だけ歯科医の段に入れる
- 全員が休みの日は「休診」。祝日でも出勤者がいれば通常どおり
- 前後の月のマスは日付のみ（薄い色）。上の「有給：」欄は空欄
- 祝日は自動計算（春分・秋分は近似式、振替休日・国民の休日対応）

ルールに変更を頼まれたら `make_calendar.py` とこのファイルを更新する。
