# 月次レポート（Excel版）

`博多ステラ歯科_月次レポート.xlsx` … 毎月シートを追加して使い回す月次レポート。

| シート | 内容 |
|---|---|
| 2026年10月 | 当月レポート（KPI／日計業務／月売上／自費内訳／エアフロー／Apotool／参考：ホワイトニング／所見） |
| 推移 | B列に月シート名を入れると主要KPIを自動で読み込む一覧 |
| テンプレート | 入力欄が空の月次シート。コピーして翌月に使う |
| 使い方 | 運用手順・凡例・計算式 |

- 青字（クリーム色）＝入力値、黒字＝数式
- 月売上 ＝ 合計点数×10 ＋ 自費請求額（個人別） ＋ 販売品目（未収金は含めない）
- 達成率 ＝ 月売上 ÷ 月目標（1,000万円）
- キャンセル率 ＝ キャンセル数 ÷（来院件数＋キャンセル数）
- 金額は「¥11,053,540（約1,105万4千円）」形式で併記（千円単位で四捨五入）

再生成: `python monthly-report-excel/build_monthly_report.py`
