# 受付報告

院長・阿比留さん・片山さんの3人が同じページを見て、報告・相談とその返事を
やり取りするためのシステムです。受付がその場で上げた報告に院長が返し、
1日の終わりにその日のまとめを残します。

**公開URL**: https://claude.ai/artifact/St9NAWan1niW27azwX2HRK

以前の「受付メモ」と同じアーティファクトを作り替えたものなので、
ホーム画面に置いたアイコンや古いリンク（`claude.ai/code/artifact/d1988dc7-…`）からも
そのまま開けます。

## はじめの設定

3人とも同じ Google アカウント（hakata.stella@gmail.com）でログインして使うため、
**ページ側では誰が開いているか分かりません**。そこで、端末ごとに一度だけ名前を選びます。

1. それぞれのスマホで上のURLを開く
2. 「この端末はどなたですか？」で **院長 / 阿比留 / 片山** から自分を選ぶ
3. ホーム画面に追加しておく（次からは1タップ）

選んだ名前はその端末に保存され、次からは聞かれません。右上のボタンでいつでも
切り替えられるので、共用のPCなど複数人が触る端末でも使えます。

名前を増やす・変えるときは `index.html` 冒頭の `MEMBERS` を直します。

## 使いかた

下の入力欄に打って ↑ で送る。返事や対応が必要なものは **「返事がほしい」**
（院長側は「対応してほしい」）にチェックを入れます。
相手のカードには **確認 / 返信 / 完了** のボタンが出ます。

### 立場で変わるところ

| | 受付（阿比留・片山） | 院長 |
|---|---|---|
| 入力欄 | 報告・相談を入力 | 指示・連絡を入力 |
| チェックの意味 | 返事がほしい | 対応してほしい |

### 「要対応」に入る条件

いま自分が動くべきものだけが数えられます。

| できごと | 阿比留 | 片山 | 院長 |
|---|---|---|---|
| 阿比留が相談を出した | − | − | ◯ |
| 院長が返信した | ◯ | − | − |
| 院長が指示を出した | ◯ | ◯ | − |
| 誰かが指示を「完了」にした | − | − | − |

院長への相談は**院長が返信すれば片づき**、院長からの指示は**「完了」を押すまで**
受付2人の要対応に残ります。やるべき仕事と、答えれば済むことの違いに合わせています。
受付どうしは、相手の相談を肩代わりしなくていいように、自分の投稿への返信だけが
自分の要対応に入ります。

### タブ

- **すべて** — 全部の履歴を、新しい日が上に来る順で
- **要対応** — いま自分が動くべきものだけ。件数が出ます
- **今日** — 今日のぶんだけ

### 1日のまとめ（日報）

今日の欄の先頭に「＋ 今日のまとめを書く」が出ます（受付のみ）。
来院数や気づいたことを書いておくと、その日のカードとして残り、院長からも読めます。

## 状態の見かた

| 表示 | 意味 |
|---|---|
| 未読 | 相手がまだ見ていない |
| 確認済み | 相手が「確認」を押した |
| 要返事 / 対応おねがい | 返事または対応が必要 |
| 返事待ち / 未対応 | まだ返ってきていない |
| 返信あり | 返事がついた |
| 完了 | この件は終わり（「戻す」で開き直せます） |

## 保存のしくみ

- 送信・確認・返信・完了のたびに、このページ自身が新しいバージョンとして保存されます
- **開いている相手の画面は、保存に合わせて更新されます**。院長が開いたままなら報告はそのまま届きます
- 端末側にも控えを持つので、電波が悪くても入力は消えません。つながったときに保存されます
- 3人が同時に書いても、投稿単位・返信単位で突き合わせて統合するので取りこぼしません
- ヘッダーの表示が保存状態です（保存済み／保存中…／保存できません／この端末のみ／閲覧のみ）

### リアルタイム同期（db）を使っていない理由

この環境では `db` 機能（ページ外にデータを置いて即時同期する仕組み）も使えますが、
db を使うページは同じ組織のメンバーしか開けないという制約があります。
3人が同じアカウントで使う今の運用なら db でも動きますが、将来それぞれのアカウントに
分ける可能性を考えて、組織外の人を招待しても動く現在の方式にしています。
アカウントを分けない方針が固まれば、db 方式に切り替えて
リロードなしの即時反映にできます。

## アカウントについて

3人が同じ Google アカウントを共用するため、**このアカウントで作ったものは
全員が見られます**（他のアーティファクト、チャット履歴を含む）。
給与や人事に関わるものを同じアカウントに置く場合は、その前提でお使いください。
分けたい場合は、院長だけ別アカウントにして共有メニューから編集権限で招待する形にもできます。

## 開発メモ

`index.html` が本体です（1ファイル完結、外部依存は Google Fonts のみ）。
状態はページ内の `<script id="app-state">` に JSON で埋め込まれ、保存時はページ自身の
公開ソースを取得してこのブロックだけを差し替えて再公開します。

投稿は `by`（メンバーID）を持ち、`MEMBERS` の `side`（director / reception）が
挙動を決めます。初期版の `from: "reception" | "director"` も読めるようにしてあります。

更新するときは同じファイルを再公開すればURLは変わりません。**再公開の前に必ず
公開中の版を読み、その時点の `app-state` を新しいファイルに引き継いでください。**
引き継がずに公開すると、やり取りの履歴が消えます。
